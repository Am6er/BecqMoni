## What this is

BecquerelMonitor ("BecqMoni") — a Windows Forms desktop application for gamma-ray
spectroscopy: it acquires spectra from radiation detectors, performs energy/FWHM
calibration, detects photopeaks, and identifies nuclides. It is an enhanced fork of the
original BecquerelMonitor. Target: **.NET Framework 4.8**, C#, `WinExe`, `AnyCPU`.
Distributed with autoupdate at https://amba.cloud/becqmoni.
