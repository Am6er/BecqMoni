# AGENTS.md — BecqMoni

BecquerelMonitor — WinForms-приложение гамма-спектрометрии, C#, .NET Framework 4.8.

## Постановка и реестр

- На вопрос «почему» сначала ответить по существу. Дефекты приложения приоритетнее корпуса и оснастки. Соблюдать границы поручения.
- При новой постановке до первой правки применять [разбор задачи](.agents/skills/becqmoni-analyst/SKILL.md). На продолжении, ответе пользователя, запросе статуса или команде коммита повторный разбор не требуется.
- Искать задачу в `TODO.md` и `DONE.md`, включая таблицу отказов, затем читать связанный журнал. Для выбранных строк или серии применять [навык работы по TODO](.agents/skills/becqmoni-todo-work/SKILL.md).
- Реестр ведёт координатор. В TODO хранить задачу и ссылку на журнал решений и измерений. Найденное записывать в существующую задачу. Новую строку заводить только для действия после поиска родительской задачи и дублей.
- Закрытие подтверждать измерением. Строки не удалять. Перенос в DONE — только по прямому поручению пользователя. Решение о закрытии серии AMBER принимает пользователь.

## Защищённые данные

- Пользовательский конфиг не редактировать. GUI запускать на копии конфига. Поставочные `NuclideDefinition.xml` и `config/device` защищены. В задачах по `config/ROI` сверять датированное решение пользователя из-за расхождения с прежним запретом.
- Изменение баз, включая объявленную базу, требует отдельного решения пользователя. Согласование метода не разрешает запись. Не подгонять данные или паспорт под модель. Не трогать `NonlinearEnergyCalibration` и не заводить новых задач по германию.

## Сборка и проверка

- Все сборки выполнять в `D:\BqMoni_Claude`. MSBuild запускать через PowerShell с абсолютными `OutputPath` и `IntermediateOutputPath` в отдельных подкаталогах задачи. Флаги диагностики и ClickOnce сверять с [рецептом сборки](.agents/references/rules/section-05.md).
- Для матриц, корпуса и замеров скорости применять [правила расчётов](.agents/skills/becqmoni-todo-work/references/operations.md). Для замеров скорости также читать [правила профилирования](.agents/references/rules/section-06.md).
- Для приёмки коммита требуется `python tools/check_all.py` с кодом 0. Не скрывать сбой новым исключением. Изменения UI проверять на нужном экране приложения. Для проверки отказа или сторожа обязателен положительный контроль.

## Файлы и соглашения

- Временные расчёты и worktree размещать в своей полосе `D:\BqMoni_Claude` независимо от имени продукта. Существующие каталоги проверять перед использованием. Канонические сборки и склады не удалять.
- Разрешённые коммиты делать поимённо по своим путям, сохраняя чужой индекс. Скриншоты и личные данные в публичный git не помещать.
- Перед исправлением искать все вызовы, включая callbacks, overrides, сериализацию и отражение.
- Английские ресурсы первичны; русский перевод обновлять в парном .ru.resx. Числа читать и писать InvariantCulture: десятичная точка, без группировки разрядов.
- В новых русских текстах: импорт/экспорт, FSA, FWHM, гид. Старые журналы и цитаты не переписывать. Сохранять кодировку и фактические переводы строк по байтам.
