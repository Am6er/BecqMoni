## 1. Вывод нормировки (с розыгрышем)

**Схема.** Точки равномерно по поверхности сферы радиуса R вокруг детектора,
направление ВНУТРЬ по закону косинуса (ламбертова сфера). Яркость L вдоль
луча в пустоте сохраняется, у ламбертовой поверхности она одна во все стороны
— значит в любой внутренней точке из любого направления приходит та же
яркость: поле однородно и изотропно. Испускание N квантов с площади 4πR² при
светимости πL: N = πL·4πR². Флюенс внутри Φ = 4πL = N/(πR²), то есть **на
один испущенный квант 1/(πR²) в любой точке**.

Отсюда `A_эфф [см²] = π·R²·ε_R`, где ε_R — «счёт на квант, испущенный сферой».

**Розыгрыш** (`scratchpad/iso_theory2.py`, 2·10⁶ точек, флюенс — точным
интегралом по конусу малой пробной сферы):

| R, см | z/R пробной точки | ламберт: Φ·πR² | изотропно с поверхности: Φ·4πR² |
|---|---|---|---|
| 50 | 0.0 | 1.0000 | 1.0000 |
| 50 | 0.3 | 0.9998 | 1.0315 |
| 50 | 0.6 | 0.9995 | 1.1546 |
| 50 | 0.9 | 0.9977 | 1.6323 |
| 100 | 0.0 | 1.0000 | 1.0000 |
| 100 | 0.9 | 0.9997 | 1.6364 |

Ламбертова сфера — однородное поле до 0.1 % на всём радиусе; изотропный
розыгрыш с поверхности — поле, растущее к стенке в 1.63 раза. Поэтому закон
косинуса — не выбор, а условие.

**Откуда 5.55 (`E35`).** Схема `E35` — цилиндр R×2R, заполненный равномерно
объёмными изотропными источниками, прибор в центре. Флюенс в центре от
объёмного источника плотности s: Φ = s·⟨R⟩, ⟨R⟩ — усреднённая по углу
радиальная протяжённость; для цилиндра R×2R ⟨R⟩ = R·(−ln cos(π/4) + π/4) =
1.132 R (розыгрыш: 1.1315). Объём 2πR³, ε = A·⟨R⟩/V → A = ε·2πR³/(1.132 R) =
5.55·ε·R². **Формула верна для своей схемы** и там сходится лишь
асимптотически (поле объёмного цилиндра неоднородно, нужно R ≫ детектора). Для
ламбертовой сферы коэффициент — **π**, и равенство точное при любом R,
накрывающем сцену. Расхождение 5.55 против π — не ошибка `E35`, а разные схемы
розыгрыша; в дерево ушла сферическая.

**Реализация в весе истории.** Обходы `OneHistory`, `AnalogContinuumRun`,
`TotalEfficiency` разыгрывают направление изотропно (плотность 1/(4π)) либо
конусом на габарит с весом Ω/(4π) — то и другое есть «изотропно в 4π».
Ламбертова плотность cos θ/π; отношение 4·cos θ (наружу — 0). Вместе с πR²:
вес истории = **4πR²·cos θ** [см²] — `EfficiencySimulator.IsoFieldSampler.DirectionWeight`.
У всех прочих источников `DirectionWeight` = 1.0, умножение точное, прежние
сцены побитово прежние (§4).

**Коши.** Для выпуклого тела в изотропном поле число входящих квантов =
Φ·S/4 (средняя проекция = S/4). У голого цилиндра Ø63×63 мм: S = 2πr²+2πrh =
186.9 см², S/4 = 46.76 см²; розыгрыш проекций дал 46.757. Это аналитическая
сверка пробы (§3).

## 4. Формула для потребителя дозы (`AMBER18`, `DoseRate*.cs` — не трогал)

Сцена `ISO` отдаёт **эффективную площадь** A_эфф(E), см² — на квант/см²
изотропного поля, — строкой матрицы (сумма строки = A_полн(E), бин пика =
A_пик(E)) и кривой (A_пик(E)). Тогда для линии энергии E:

    φ̇(E) [квант/(см²·с)] = N_E [имп/с] / A_эфф(E) [см²]

где N_E и A_эфф берутся ОДНОГО рода: площадь пика ↔ A_пик (кривая или бин
пика строки), полный отклик линии ↔ A_полн (сумма строки; так делит
полноспектральный разбор). Дальше — тем, что уже лежит в `DoseRate.cs`
полосы `AMBER18`:

    Ḣ*(10) [мкЗв/ч] = Σ_E φ̇(E) · DoseRatePerFluenceRate(E)
    DoseRatePerFluenceRate(E) = Factor(E) · MicroSievertPerHourPerFactor
    Factor(E) = (μ_en/ρ)_air(E) [м²/кг] · h*(10)/K_air(E) [Зв/Гр] · E [кэВ]
    MicroSievertPerHourPerFactor = 10 · 1000 · 1.602176634e-16 · 1e6 · 3600
                                 = 5.768e-4 [мкЗв/ч на квант/(см²·с)] на (м²/кг·Зв/Гр·кэВ)

Сверка уровня (независимо от `DoseRate.cs`): 662 кэВ, (μ_en/ρ)_air = 0.0294
см²/г, h*(10)/K_air = 1.20 → 662·1.602e-13·0.0294·1.20 = 3.74 пЗв·см², ICRP 74
(интерполяция A.21 между 0.6 и 0.8 МэВ) 3.73; `DoseRate.cs` называет 3.71 —
согласие в 1 %. Механически: дозе нужна матрица (или кривая) сцены `ISO` для
ТОГО ЖЕ детектора — отдельная геометрия «прибор + поле», ≈ цена одной сцены
склада; в конфигурации прибора она различима по `norm=fluence` в клейме кривой
и `Normalization == PerUnitFluence` у матрицы. ⛔ Складывать отклик матрицы поля
с откликом матрицы пробы нельзя — см² с долями; признак для этого и заведён.
