Правило (`correct_lnhb_alpha.py`, шапка):
* **α**: строка поставки с парой в LNHB (|ΔE| ≤ max(0.6 кэВ, 5·10⁻⁴·E), ближайшая, один к одному) — НА МЕСТЕ, номер `dr_pk` тот же; линия LNHB без пары — новая строка 400001…; строк поставки без пары нет. Неразрешённая группа (↑|↓) — одной строкой на энергии последнего члена, как в `.lara.txt`; ≈/∼ → `AP`.
* **β⁻**: пара по границе в допуске max(15 кэВ, 1 %); сдвиг границы в допуске номера (`AMBER281`, max(1 кэВ, 0.2 %)) — на месте, больше — новая строка, прежняя ОСТАЁТСЯ как была и пишется заменённой в `decay_radiations_superseded` (`dr_pk`, `by_dr_pk`, `source`, `note`; таблицу заводит `correct_lnhb_alpha.py`). Решение Amber 14.11.2026 вопросником (третий круг), дословно: **«Строка остаётся, отсев (Рекомендую)»**. Отсев — у читателей β: довесок `DecayParentRule.NotSupersededClause` (`and dr_pk not in (select dr_pk from decay_radiations_superseded)`, без таблицы — пусто) у `FsaSampleLibrary` (запрос ветвей β⁻/β⁺ и гамм — через него `FsaBetaLibrary` и слой кристалла; запрос гамм, рентгена и β⁺ состава), `CascadeAtomicData` (все строки родителя — доля β⁺) и `tools/nucdb/import_beta_shapes.py`. Читатели только гамм и рентгена (генератор корпуса `chains.py`/`build_corpus.py`, `xray_rule.py`, `NucBaseFramework`, `add_isomer_edges.py`) довеска не несут: заменяются только строки β — это держит сторож `tools/check_nucdb_superseded.py` (заменённая гамма — отказ, читателей придётся дописать). Без таблицы прежний отсев «дублей второй оценки» (`FsaBetaLibrary.Screen`) оставил бы у Tl-207 строку ПОСТАВКИ 1431 и выбросил бы 1418 LNHB (замер — §5): таблица замен здесь не украшение. Пределы LNHB («<») не берутся и печатаются: Tl-207 848 кэВ < 0.00008 %, Pb-211 600 кэВ < 0.09 %.
* **Ac-227 β⁻** (решение «Нормировать к 98.62 %», поправка Д1): ЧИСЛО выхода (`intensity_num`) приближённых ветвей «≈53, ≈35, ≈10» умножено на (98.62 − 0.3)/98 = 1.003265 (53.1731 / 35.1143 / 10.0327), ТЕКСТ (`intensity`) — как у LNHB (`53`/`35`/`10`, признак `AP`) — так устроена поставка (Bi-211: текст `83.54`, число 83.5387948).

**(а.) Нормировка альф на долю моды у читателя** (`CrystalOwnActivityBuilder.AlphaLines`). Σ строк α не равна доле α-моды (Th-227 100.32 %, Ra-223 100.82 %, Rn-219 100.03 %, Ac-227 1.422 % при моде 1.38 %). Без нормировки слой берёт 5.009 альфы на распад головы, с нормировкой — 4.997. Вставить внутри `using (var connection …)` после второго `using (SqliteCommand …)` (чтение `rows`):

```csharp

                double mode = 0.0;
                using (SqliteCommand command = connection.CreateCommand())
                {
                    command.CommandText = "select perc_num from l_decays where nucid = $n and l_seqno = 0 and dec_type = 0";
                    command.Parameters.AddWithValue("$n", nucid);
                    object v = command.ExecuteScalar();
                    if (v != null && !(v is DBNull))
                    {
                        mode = Convert.ToDouble(v, CultureInfo.InvariantCulture);
                    }
                }

                double rowSum = 0.0;
                foreach (double[] r in rows)
                {
                    rowSum += r[1];
                }

                if (mode > 0.0 && rowSum > 0.0)
                {
                    foreach (double[] r in rows)
                    {
                        r[1] *= mode / rowSum;
                    }
                }
```
