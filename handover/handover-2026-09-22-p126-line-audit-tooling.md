### 1.3. Правка

`FsaLineAudit.Run(spectrum, result, fwhm, library, backgroundSpectrum)` — пятый аргумент, спектр вычтенного фона;
масштаб s = `spectrum.EffectiveLiveTime / background.EffectiveLiveTime` тем же правилом, что у анализатора (`AMBER35`).
Разбор, взявший фон (`BackgroundUsed`), без спектра фона — `ArgumentException` с причиной, не молчаливая единица.
`Measure`: `variance += data + s·bg`; порог `L_C = k·√(cont + bg + s·bg)`.

**Вывод порога и источник.** Карри (Currie L.A., «Limits for Qualitative Detection and Quantitative Determination»,
Anal. Chem. 40 (1968) 586–593): критический уровень L_C = k_α·σ₀, где σ₀ — стандартное отклонение ЧИСТОГО сигнала
при его истинном нуле. Чистая площадь здесь S = G − B̂ − C: G — брутто-счёт окна (пуассон, при нуле сигнала
E[G] = C + B → Var G = C + B), B̂ = s·N_фона — оценка вычитаемого фона (Var B̂ = s²·N_фона = s·B), континуум фита C
берётся как есть (без дисперсии — как и прежде, у обеих сторон сравнения). Итого σ₀² = C + B + s·B, k = 1.645
(α = 5 %). Проверка на пределах Карри: s = 1, C = 0 — «парные наблюдения», L_C = 1.645·√(2B) = 2.33·√B; s → 0 —
«хорошо известный фон», L_C = 1.645·√B. Прежний порог `k·√(C + B)` члена фона не имел — при s = 1 он занижен в √2.

Читатель: `tools/effmaker/probes/CorpusFsaProbe.cs:3285` — подаёт `background` (тот же, что анализатору).

## 2. `SumPeakProbe.cs`: τ = A/(2·R·N) — половина (append к `AMBER49`)

**Определение.** Колонка наложений `((s⊗s)/N − 2·s)/N` (после `AMBER49`, П120); модель `s' = s·(1 − 2Rτ) +
Rτ·(s⊗s)/N` (Wielopolski & Gardner 1976; Knoll гл. 17) → амплитуда A = Rτ·N — ЧИСЛО ПАР (у импульса в среднем 2Rτ
соседей в окне ±τ, пара считается один раз: N·2Rτ/2 = N·R·τ). Значит τ = A/(R·N). Проба печатала A/(2·R·N).
Откуда двойка: ~~`S22`~~ (08.08.2026) определяла τ по площадям как A₁₃₂₄/(2·r₆₆₂·A₆₆₂) — формулой 2·τ·R1·R2·t для пары
РАЗНЫХ линий, применённой к паре одной линии (удвоение неупорядоченных пар), и печать 1.400 сходилась с 1.424 того же
определения: две ошибки в одну сторону = «сошлось».

**ДО** (стенд `D:\BqMoni_Claude\p126\wd` = `build_p126` + конфиг витрины, рецепт `mk_wd.ps1` П120; спектр
`tools/fsa_showcase/spectra/ASN16_Cs137_house.xml`, `--sample=Cs-137 --pair=661.657:661.657 --window=1283:1363`):
250 626 474 отсч., живое 356 491.2 с, R = 703.0 имп/с; плечо «+наложения»: амплитуда 4.916E+005 = 1.961E-003·N,
z = 28.9, **τ = 1.395 мкс**. Оценка по площадям в той же пробе: 2·τ·R1·R2·t (двойка и для одной линии).

**Правка** (`tools/effmaker/probes/SumPeakProbe.cs`): τ = A/(R·N) и печать множителя `A/N`; в строке «случайные
совпадения» множитель очерёдностей 2 для разных линий и 1 для `--pair=E:E`, и рядом — τ из площадей
NΣ/(множитель·R1·R2·t) как путь без модели; описание τ в шапке пробы.

**ПОСЛЕ:** **τ = A/(R·N) = 2.790 мкс**; из площадей (net 662 = 65 294 972, net сумм-окна 35 840):
τ = 35 840/(183.16²·356 491) = **2.997 мкс** — два пути одного определения сходятся на 7 % (окно суммы широкое, ±130
кэВ, и часть сумм-континуума 662+комптон ложится в него; до правки они расходились вдвое). Паспортного разрешающего
времени прибора ASN16 в журналах `handover/*pileup*`, `*sum*`, `handover-response-matrix.md` не названо — сравнить не с
