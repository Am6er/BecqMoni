## 1. Шаг 1 — модель и ключ

### 1.1 Что сделано, где

* **Новый файл `BecquerelMonitor/EfficiencyMaker/ElectronTransport.cs`** — вторая половина
  `EfficiencySimulator` (класс стал `partial`; настроечные поля остались в главном файле,
  их читает сторож `check_matrix_keys.py`). Внесён в `BecquerelMonitor.csproj`.
* **`EfficiencySimulator.ElectronTransport`** (bool, ВЫКЛ) и **`ElectronStepFraction`**
  (0.1 — доля остаточного пробега на шаг, рычаг сходимости, в клеймо не входит).
* **`ElectronLoss`** получил перегрузку с направлением рождения
  (`ElectronBirth` — `Isotropic` / `Photo` / `Given` / `Pair` + опорный вектор); прежняя
  пятиаргументная — обёртка с `Isotropic` (оже-электроны каскада). Вызовы: фотоэффект
  (оба места и `PhotoElectronsSplit`) — `Photo` с направлением кванта; комптон
  (и `VacancyElectronsSplit`) — `Given` с импульсом `p_γ(до) − p_γ(после)`, для чего
  направление до `Rotate` сохраняется в трёх локальных; пара — `Pair` с направлением
  кванта (обе ветви `PositronTransport`). Без ключа ни одно из этих направлений не
  читается и случайных чисел не тянет.
* **Ветка переноса в `ElectronLoss`**: `if (ElectronEscape && ElectronTransport)` —
  направление рождения по процессу → `TransportElectron`; иначе прежняя эффективная
  глубина до последнего бита. Тормозное (статья 1) — одно на обе ветки; зажим
  «унести не больше `te − radiated`» тот же.

### 1.2 Модель (`ElectronTransport.cs`)

1. **Направление рождения.** Фотоэлектрон — Заутер—Гаврила для K-оболочки, розыгрыш
   отбором как в `G4SauterGavrilaAngularDistribution`; комптоновский электрон — из
   кинематики (нормированная разность импульсов кванта); лептон пары — модифицированный
   Цай (`G4ModifiedTsai::SampleCosTheta`) относительно кванта; электроны каскада EADL —
   изотропно.
2. **Шаг по пробегу CSDA** (ESTAR из `matdb`, `ElectronData.RangeOf` /
   `EnergyOfRange`): остаточный пробег `R`, шаг `ΔR = 0.1·R`; энергия в конце шага —
   обратной таблицей. Разброса потерь (Ландау) и δ-электронов нет (сгущённая история
   класса I).
3. **Многократное рассеяние — случайный шарнир (PENELOPE):** шаг проходится прямо до
   случайной точки `ξ·Δs`, там поворот на угол всего шага, дальше прямо `(1−ξ)·Δs`.
   Ширина — формула Хайленда в редакции PDG (`θ₀ = 13.6 МэВ/(βcp)·√(x/X₀)·(1 + 0.038·ln(x/(X₀β²)))`,
   скобка зажата снизу 0.25), энергия — в середине шага; распределение `1−cos θ` —
   экспонента со средним `θ₀²`, обрезанная на 2 (при малых `θ₀` — рэлеевский угол
   Хайленда, при больших — изотропия). Радиационная длина кристалла — из состава по Цаю
   (массовые доли `GeometryMaterial.Fractions`, массы `MaterialDatabase.AtomicMass`):
   CsI 8.39 г/см², NaI 9.49 — сходится с PDG в третьем знаке.
4. **Вылет — реальный:** прямой отрезок пересёк грань (`CrystalPath`) — электрон уходит
   с энергией по остаточному пробегу в точке выхода. Обратно из обвязки не возвращается
   (вести вне кристалла нечем — как и позитрон).
5. **Цена держится ранним выходом:** перед первым шагом и после каждого — остаточный
   пробег против расстояния до ближайшей грани (`CrystalNearestFace`, нижняя граница
   пути по любому направлению): короче — погибнет внутри при любой траектории, остаток
   кладётся на месте без единого розыгрыша.

Не тронуто: `PositronStop` (точка аннигиляции — прежняя эффективная глубина, «пара — по
существующей схеме»), тормозное (`M3`), `EstarCalculator`/`MaterialDatabase` (только
чтение), занос электронов из обвязки (`ElectronCarryDetour`).
