## 2. `A285`: смещение амплитуд от Хубера — измерено

### 2.1 ⛔ Ключ доехал до РЕШЕНИЯ, а не до печати — числом, на первых ДВУХ

Признак выбран так, чтобы печать его подделать не могла. Без `--gamma`/`--beta`
веса решателя РАВНЫ отчётным, значит при `HuberM = 0` (один проход, веса не
пересчитываются) `chi2ndf` обязан СОВПАСТЬ с `chi2ndf_pois`; при поставочном
Хубере — разойтись.

| спектр | поставка: реш. / пуас. | равны | `--huber=0`: реш. / пуас. | равны |
|---|---|---|---|---|
| `AS80_Cs137_0cm` | 14.6905 / 417.3374 | нет | 415.2125 / 415.2125 | **ДА** |
| `AS80_Lu176` | 5.9294 / 216.8580 | нет | 216.6575 / 216.6575 | **ДА** |

Второй, независимый признак того же: при `--huber=0` решатель минимизирует
ИМЕННО отчётную метрику, значит она обязана УПАСТЬ — Σχ²_пуассон понятной части
**31755.8 → 28980.1** (−8.7 %). Оба признака сходятся.

### 2.2 Смещение амплитуд, по частям корпуса и поимённо

Крупнейшие, понятная часть: `G1S16_Cd109_P5` Cd-109 **+92.50 %** (49.1 → 94.5),
`G1S16_Ba133_P5` Ba-133 **−87.19 %** (2075 → 265.9), `G1S16_Ba133_P25` −54.93 %,

задана не данными, а выбором настроек решателя, и разброс по четырём законным
настройкам — множитель 1.83.**

## 3. `A281`: что даёт снятие `inflate` при уже понятом Хубере

### 3.1 Сколько стоит множитель сегодня — на нынешнем дереве

Малая база, по частям (⛔ не складывать):

| часть | спектров | медиана | минимум | максимум | зажат единицей |
|---|---|---|---|---|---|
| понятная | 42 | **2.444** | 1.000 | **8.163** (`G1S24_Eu152_P5`) | **1** |
| непонятная ⚠ | 2 | 6.266 | 4.734 | 7.798 | 0 |

То есть жёсткий порог 3 означает сегодня в понятной части **от 3.0 до 24.5
«сырых» сигм** при медиане **7.3**, и «зажат единицей» — не правило, а исключение
(1 спектр из 42). По всем 44 разобранным вместе медиана 2.606.

### 3.2 Вариант И2 (убрать множитель) — пересчёт колонки z, без правки кода

`sigma = √inv(Gram)·inflate`, множитель ОДИН на весь спектр, значит z без него
равен ровно `z·inflate` (`handover/p9-pogreshnosti/rescale_z.py`, 103 строки).

| часть | порог | 3 | 4 | 6 | 10 |
|---|---|---|---|---|---|
| **понятная** (42) | как есть | 100 % | 100 % | 98 % | 95 % |
| | без `inflate` | 100 % | 100 % | **100 %** | **100 %** |
| **непонятная** (⚠ 2 из 17) | оба плеча | 7 % | 7 % | 7 % | 7 % |

Фантомов **0 → 0** при всех порогах в обеих частях. ⚠ Непонятная часть здесь не
меряет ничего (гейт `A277`), и слабость довода «фантомов не прибавилось» та же,
что назвала П31: библиотека собирается по объявленной пробе (`S56`).

### 3.3 ⛔ Новое: `inflate` и Хубер — ДВА РЫЧАГА ОДНОГО, и крутят в РАЗНЫЕ стороны

| движение | понятная часть, recall | Σχ² решателя |
|---|---|---|
| поставка | 100 % (порог 3), 95 % (порог 10) | 566.4 |
| снять `inflate` | 100 % / **100 %** | 566.4 (фит не меняется) |
| снять ХУБЕРА (`--huber=0`) | **93 %** / — | **28980.1** |

Оба множителя питаются одной и той же невязкой; но `inflate` только раздувает σ,
а Хубер меняет ещё и сам фит. **Снять Хубера ДОРОЖЕ, чем снять `inflate`:**
−7 пунктов recall против +5. На синтетике `synP`, где модель верна, оба движения
стоят НОЛЬ (χ²/ndf 0.92 ⇒ `inflate` = 1.000 по построению, смещение 0.001 %).

### 3.4 ⚠ Замер, разошедшийся с ожиданием — записываю как есть

Ожидал, что `inflate` окажется целиком порождением полосы ниже 100 кэВ (там 76.8 %
всего χ²). **Не подтвердилось.** Отчётный χ² — да, три четверти его снизу; а вот
χ² РЕШАТЕЛЯ (хуберовский, он и питает `inflate`) берёт оттуда медианой лишь
**19.6 %** (15 спектров понятной части, у которых восстановление воспроизводит
число приложения точнее 10 %; на остальных реконструкция негодна, и они в свод
не идут — `inflate_where.py` печатает этот контроль по каждому спектру).
Убрать всю полосу ниже 100 кэВ из `inflate` — медиана **4.355 → 3.614**, то есть
минус шестая часть, а не «в разы». **Хубер уже подавил низ; `inflate` набирается
со всей шкалы.**

## 4. `A283`: кто врёт ниже 100 кэВ — назван замером

### 4.1 Посылка строки сверена с деревом и подтверждена

`A283` говорит: 85–87 % χ² ниже 100 кэВ на 3.2–3.5 % каналов, на двух сценах.
Малой базой, понятная часть, **41 спектр**: доля χ² ниже 100 кэВ — **медиана
76.8 %**, кварт. 18.1 … 94.4 %, на 3–6 % каналов. Непонятная (⚠ 2 спектра) —
99.2 %. Посылка не только держится, она общая для части, а не свойство двух сцен.

Крайние примеры: у `G1S24_Ba133_P5` **ОДИН канал** (ch 11, 21.70 кэВ) держит
**51.3 % χ² всего спектра**; у `ASN16_Cs137` полоса 15.2…24.4 кэВ (25 каналов из
8192) держит больше половины.

### 4.2 Четыре подозреваемых строки — разведены одним и тем же опытом

К модели применяется ОДНО преобразование, отвечающее подозреваемому, и меряется,
сколько χ² оно снимает. ⛔ **Полоса ВЫШЕ 100 кэВ — встроенный положительный
контроль:** преобразование, снимающее и там, меряет свою гибкость, а не беду.
(`handover/p9-pogreshnosti/shift.py`, дамп со столбцом `fit` — `A284`.)

| сцена | **Ш** сдвиг шкалы | **У** уровень (эффективность) | **Р** размытие (форма пика) | **К** добавка (потолок континуума) |
|---|---|---|---|---|
| `G1S24_Ba133_P5` | **84.7 %** / 1.2 % | 2.5 % / 28.9 % | 28.6 % / 0.0 % | 73.5 % / 72.2 % |
| `G1S24_Am241_P5` | **62.2 %** / 0.8 % | 9.4 % / 2.6 % | 19.5 % / 1.1 % | 39.9 % / 11.1 % |
| `G1S24_Eu152_P5` | **27.3 %** / 6.1 % | 1.4 % / 17.0 % | 13.6 % / 0.0 % | 19.5 % / 36.4 % |
| `ASN16_Cs137` (⚠ непонятная) | 3.4 % / 15.9 % | 0.5 % / 16.0 % | 2.8 % / 1.4 % | 96.5 % / 91.2 % |

(в клетке: снято НИЖЕ 100 кэВ / снято ВЫШЕ — контроль)

По всей понятной части (41 спектр): сдвиг снимает внизу **медиану 52.3 %**, тот же
сдвиг наверху — **2.7 %**, разделение в 19 раз. Сдвиг ОТРИЦАТЕЛЕН (модель стоит

⇒ **Эффективность оправдана** (внизу 0.1–9 %, наверху 2.6–28.9 % — работает не там).
⇒ **Континуум оправдан**: «добавка» — это ВЕРХНЯЯ ОЦЕНКА того, что способен взять
на себя любой континуум, и она не различает верх и низ (73.5 против 72.2), то есть

⇒ **Форма пика — вторична**: 13.6–28.6 % внизу при 0.0 % наверху. Есть, но втрое
слабее сдвига.
⇒ **Отклик оправдан косвенно**: `ASN16_Cs137` матрицы не имеет вовсе, а болеет так же.

внизу разнос.

⚠ **И сетке дрейфа шанса не было:** у ВСЕХ 44 разобранных спектров подогнанные
`gain = 1.000000`, `offset_ch = 0.000` — умолчание `GainSteps` = `OffsetSteps` = 1,
то есть дрейф не ищется вовсе. Даже если бы искался, он ЛИНЕЕН и ОБЩИЙ на весь
спектр, а требуемая поправка при 662 кэВ равна нулю и при 32 кэВ — четверти.

### 4.4 ⛔ У виновника УЖЕ ЕСТЬ СТРОКА — `B25`

`B25` («ШКАЛА G1S НИЖЕ ~45 кэВ», открыта, переписана 31.08.2026 решением Amber)
описывает ровно это: медиана промаха −0.79 ПШПВ на 14 спектрах G1S с чистой
группой рентгена, худший `G1S16_Ce139_P5` −1.29, положительный контроль по сильной
линии выше 100 кэВ — медиана −0.01. Причина в манифесте: `ecal_mode` = `affine`
на 2–6 опорных линиях (`G1S24_Ba133_P5`: `affine/grp`, 4 линии, rms 3.39 кэВ;
`G1S16_Cd109_P5`: `gain/grp`, 2 линии, rms 9.57), то есть внизу шкала
ЭКСТРАПОЛИРОВАНА прямой. `B25` уже несёт и приписку `AMBER10` — тот же класс на
СОБСТВЕННОМ спектре Amber, а не корпуса.

**Чего в `B25` нет и что добавляет этот заход:** что этот дефект — не помеха
чтению A/B, а **ГЛАВНОЕ слагаемое всей погрешности разбора**. Он держит медианой
76.8 % всего χ² понятной части, через χ² задаёт `inflate` (медиана 2.444, максимум
8.163) и, значит, каждую значимость, а через хуберовскую подрезку — сами амплитуды
(до 92.5 %). И он НЕ только у G1S: `ASN16_Cs137` непонятной части даёт −27.2 %.

### 4.5 ВТОРАЯ, независимая беда того же низа: подпороговый вал

У `ASN16_Cs137` сдвиг не работает (3.4 %), и причина другая. Профиль:

| кэВ | данные | модель | модель/данные | доля χ² всего спектра |
|---|---|---|---|---|
| 0…10 | 4 053 798 | 88 689 | **0.022** | 11.2 % |
| 10…20 | 7 129 402 | 92 201 | **0.013** | **44.6 %** |
| 20…30 | 22 742 362 | 5 619 260 | 0.247 | 40.1 % |
| 30…40 | 5 171 073 | 16 624 751 | 3.215 | 0.5 % |
| 60…100 | сходится | | 1.00…1.08 | 0.0 % |

Ниже 20 кэВ у данных **11.2 млн отсчётов, у модели 0.18 млн** — и это **55.8 % χ²
всего спектра**. Это порог АЦП (разрядный вал), физического образа там нет и быть
не может. ⛔ **А фит туда заходит:** полоса начинается с канала 1, чья
калиброванная энергия **−13.9 кэВ**. Замер по малой базе: **полоса фита
начинается НИЖЕ НУЛЯ кэВ у 31 из 42 спектров понятной части и у 2 из 2
непонятной.** Поставочный режим `LibraryToFitByCurve` кладёт полом КРИВУЮ только
для БИБЛИОТЕКИ, а фит идёт по всему спектру (так решено 25.08.2026 замером, и
довод — что `FitToLibrary` режет нижние половины пиков, чьи центры В ПОЛОСЕ).
Доля отсчётов полосы ниже 20 кэВ: медиана понятной части 0.66 %, но
`G1S16_Cd109_P25` **77.28 %**, `G1S16_Cd109_P5` **74.01 %**, `G1S24_Cd109_P5`
**42.96 %** — те самые три кадмиевых спектра, с которых начиналась `B25`.

Плечо `--band=fit` (сузить фит до полосы библиотеки) проверено на
`G1S24_Eu152_P5`: полоса 28.9…2800.6 кэВ, χ²/ndf решателя 66.64 → 69.08, амплитуда
Eu-152 71321 → 68119. **То есть у этой сцены беда НЕ в подпороговом вале, а внутри
полосы** — сужение её не лечит. Две беды разные, и лечатся врозь.

## 5. Что я НЕ измерил и почему

1. **Непонятная часть корпуса.** Гейт `A277` оставил 2 спектра из 17. Все числа
   этой части в журнале — указание, не мера. Полный корпус запрещён заданием.
2. **Цена починки `B25` для разбора.** Пересчёт калибровок — это пересборка
   корпуса и смена базы (решение Amber, `B25` вариант «а2»), не работа полосы.
3. **Смещение амплитуд ОТНОСИТЕЛЬНО ИСТИНЫ на настоящей сцене.** Истины там нет;
   измерено лишь расхождение законных настроек между собой (множитель 1.83) и
   отсутствие расхождения там, где истина есть (0.001 %).
4. **Реконструкция хуберовского χ² по дампу** верна не везде: сырых отсчётов в
   дампе нет, дисперсия берётся как `max(|fit|,1)`, и у спектров с крупным
   вычтенным фоном контроль расходится в разы. В свод §3.4 идут только 15 спектров
   с расхождением меньше 10 %; остальные названы негодными, а не подмешаны.
