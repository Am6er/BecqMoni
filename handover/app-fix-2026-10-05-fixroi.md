## AMBER192 — метод Ковелла и условие обнаружения

Решение Amber 05.10.2026, вопросником, дословно: **«Нет MDA → «не обнаружена»»**. МДА зоне
Ковелла НЕ давался (по указанию: не расширять).

Сделано:
* `MeasurementResultManager.cs:547-573` — ширина и центр каждого окна (боковые и сама зона) —
  по каналам ВНУТРИ спектра, ровно тем, что в суммах; окно, в котором нет ни одного целого
  канала, — отказ зоны словами (ресурс `ROICovellWindowNarrow` — «Covell window narrower than
  a channel» / «Окно Ковелла уже канала»).
* `DCResultView.cs:435-439` — условие «≥ MDA» только при `MDA > 0`: MDA не определён (−1 без
  простой разности с фоном, 0 без времени) → «не обнаружена».
* Попутно `MeasurementResultManager.cs:482-487` — у простой разности вклад в дисперсию H0 без
  квадрата коэффициента примитива; теперь `k²·bgCps·(1/t + 1/t_b)`, как у ветвей Ковелла и
  ссылки. Член `k²/t` формулы Карри общий на зону и коэффициентом не масштабируется (у зоны из
  нескольких примитивов одного k нет) — потому k = 2 даёт ×1.984, а не ×2.

| сценарий | до | после |
|---|---|---|
| 256 кан. на 3 МэВ, окна 10 кэВ, зона 600–720 | `net = NaN`, валидна | ошибка «Окно Ковелла уже канала» |
| ровно 100/кан., 1024 кан., зона 2900–2990, правое окно 2970–3010 (за краем) | `net = +145.77` | `net = 0` |
| то же в середине (1400–1490), контроль | −2.3·10⁻¹³ | −2.3·10⁻¹³ (то же) |
| Ковелл на ровном спектре, условие «≥ MDA» (MDA = −1) | «обнаружена» | «не обнаружена» |
| контроль: простая разность, пик над фоном | обнаружена, MDA 552.3 | обнаружена, MDA 552.3 |
| контроль: простая разность, спектр = фон | не обнаружена | не обнаружена |
| МДА простой разности, k = 1 / k = 2 | 552.3 / 552.3 | 552.3 / 1095.6 |

(Счёт ревизии «+442.9» стоял на другой сетке каналов; здесь своя сетка, своё «до».)

⚠ Следствие решения: зона из одного ссылочного примитива на зону с фоном тоже получает
MDA = −1 и при условии «≥ MDA» теперь всегда «не обнаружена» (прежде — всегда «обнаружена»).
