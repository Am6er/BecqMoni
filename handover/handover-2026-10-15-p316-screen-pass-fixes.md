## Ждут решения Amber (вопросы — готовым текстом)

1. **Н2 — что значит «Нет» в редакторе наборов.** Сделано: «Нет» снимает правки ЭТОГО окна (снимок на открытии).
   Перечитывание файла, как у редактора нуклидов (`AMBER196`), не взято: оно подменяет все объекты менеджера —
   выбор набора у открытых спектров держится по ссылке и молча слетел бы на «все нуклиды», а несохранённые правки
   открытого рядом редактора нуклидов пропали бы. Варианты: (а) оставить снимок — **рекомендуется**; (б) перечитывать
   файл и переносить выбор наборов по Id; (в) вопрос «Сохранить / Не сохранять / Отмена».
2. **Н12 — числа конфигурации прибора.** Сейчас отказ только для каналов ≤ 0 и отрицательного лимита времени.
   (а) Верх каналов 65536, низ 64 (как «Изменить число каналов») — **рекомендуется**; (б) 16384; (в) без верха.
   Лимит 0 сейчас значит «предел уже достигнут» — набор с такой конфигурацией не стартует молча
   (`DCControlPanel.StartMeasurement`: `ElapsedTime ≥ PresetTime`). (а) 0 — отказ словами, как отрицательное —
   **рекомендуется**; (б) 0 = «без предела» (правка набора, не только формы); (в) как есть.
3. **Н14 — поле с нечислом при уходе фокуса** (не трогалось): (а) возвращать прежнее значение без окна —
   **рекомендуется** П312; (б) оставить окно и удержание фокуса (как сейчас); то же у `DeviceConfigForm`,
   `NuclideDefinitionForm`, `AudioInputDeviceForm`, `DCControlPanel` (Н15).
4. **Слова, выбранные полосой:** «Частота дискр.» вместо «Частота дискретизации» (не помещается до поля), вкладка
   «Устройство» вместо «Особенности устройства». Устраивают ли — или вместо сокращения раздвинуть поле/вкладки.
