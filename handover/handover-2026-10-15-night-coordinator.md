## Ждут решения Amber (утренний вопросник)

1. **(подтверждение, правка уже сделана) П309 — правило П305 перенесено на AmplitudaSerial/USB**: продолжение
   файла, прибор не дал ни одного чтения (блок выключен, «Стоп» сразу) — конец набора становился «сейчас»
   (Co-60 ×1.19 у файла 2024 г.); теперь, как у RadiaCode (П305), без данных конец прежний. Варианты:
   «Оставить правку (Рекомендую)» / «Откатить — конец всегда „сейчас“».

2. **N42 пишет живое время «PT0S», где оно не задано** (П311): 585 из 907 спектров Amber и корпуса; приложение
   в таком случае делит на полное время, а SpecUtils/InterSpec читают «живое 0». Варианты: (1, рекомендует полоса)
   писать то, на что делит приложение — живое, если задано, иначе полное (при повторном импорте «живое» станет
   равным полному, числа разбора те же; перемерить ожидания `N42RoundTripProbe`, ≈30 мин); (2) оставить «PT0S», но
   назвать потерей в предупреждении экспорта (ресурс); (3) оставить.
3. **Два висячих ребра nucdb, записанных П299**: `42CR→42V` (ε 5.6 %) и `49NI→49CO` (ε 17 %) — дочерних нет в
   `nuclides`; читатели не ломаются, корни живут миллисекунды. Варианты: (1, рекомендует полоса) оставить — доля из
   `l_decays` (ENSDF), спектров не касается; (2) снять эти две строки (запись в базу — только твоим словом).
4. **Страж нуля A320 в приложении делает лишний полный разбор** (П310): когда запасной нуль не лучше вдвое, разбор
   с нулём по съёмке повторяется только ради состояния анализатора, которое читают пробы и корпус, а сеанс
   приложения выбрасывает; числа повтор не меняет (0 из 14 разошлись). У 10 из 92 понятных спектров (AS80_Th232Medal,
   AS80_Lu176, RC103_Lu176 …) разбор 13.3 → 35.5 с, из них повтор ≈13 с. Варианты: (а, рекомендует полоса) повтор
   только для проб, сеанс приложения — без повтора, ≈30 мин, проба «побитово то же» и малая база; на этих спектрах
   ×2.67 → ≈×1.67; (б) оставить как есть.
5. **Редактор наборов изотопов, «Нет» на «Сохранить?»** (П312 Н2, сделано П316): правка уже действовала в сеансе
   и молча уходила в файл при следующей записи. Ночью — откат по снимку на открытии окна, а НЕ перечитыванием файла,
   как в редакторе нуклидов: открытые спектры держат набор по ссылке, перечитывание сбросило бы их выбор на «все
   нуклиды» и потеряло бы несохранённые правки открытого рядом редактора нуклидов. Варианты: «Оставить снимок
   (Рекомендую)» / перечитывать файл и переносить выбор по Id / вопрос «Сохранить / Не сохранять / Отмена».
   ➕ Тем же решением — редактор нуклидов (П318): «Нет» перечитывал файл (код `d20d69fb`, 22.10.2025, не твоё слово) —
   открытые спектры теряли набор, «Видимый» не откатывался, занятый файл давал исключение; ночью сделан откат по
   запомненной линии. Варианты те же: «Оставить откат по снимку в обоих редакторах (Рекомендую)» / перечитывание
   с переносом выбора по Id.
6. **Пределы числа каналов и лимита времени** (П312 Н5/Н12): 2·10⁹ каналов роняло приложение (OutOfMemory), −5
   каналов и −100 с сохранялись. Ночью — отказ для каналов ≤ 0 и отрицательного лимита. Верхняя граница каналов:
   (а, рекомендует полоса) 64…65536; (б) до 16384; (в) без границы, только понятный отказ. Лимит 0 сейчас значит
   «предел уже достигнут» — набор с такой конфигурацией молча не стартует: (а, рекомендует полоса) 0 — отказ, как
   отрицательное; (б) 0 = «без предела» (правка набора, не формы); (в) как есть.
7. **Нечисло в поле** (П312 Н14/Н15): в настройках «Отмена»/крестик теперь закрывают окно; само поле при уходе
   фокуса по-прежнему держит фокус окном ошибки, а на панели управления так запирается переключение документов.
   Варианты: (а, рекомендует полоса) поле молча возвращает прежнее значение; (б) как сейчас.
8. **Стабилизатор пика тянет шкалу на шум и пустое окно** (П313, `PeakStabilizer`): раз в секунду берёт максимум
   сглаженного спектра в окне ±допуск и объявляет вершиной, не проверяя, есть ли пик. Cs-137, допуск 5 %: опорной
   линии нет — шкала молча уезжает на 22–34 кэВ (3.4–5.1 %); первые 30 отсчётов набора — скачки до 56 кэВ.
   Варианты: (1, рекомендует полоса) опора только если максимум не на краю окна и выше прямой между краями на
   ≥ 3σ, иначе шкалу не трогать — без линии принято 0 из 50, с линией опора с ≈3000 отсчётов, от 10⁴ как сейчас;
