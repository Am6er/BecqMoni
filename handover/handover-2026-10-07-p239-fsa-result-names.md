# П239, 07.10.2026 — окно результата: «в разборе нет» у Th-232

Вопрос Amber 07.10.2026, консоль, со снимком экрана и двумя спектрами (`Калибровка Th-232 (без
вычета фона) (2).xml`, `Фон_Маринелли_1_л_вода_дист_33,2_ч,_25_26_09.xml`), дословно: **«Изучи,
почему активность выдаёт "в разборе нет"?»**

Решения Amber вопросником того же дня, дословно: остаток — **«Чинить сейчас (Рекомендуется)»**;
проверка — **«Да, проверить экраном (Рекомендуется)»**. Коммит — только по её слову.

## Причина

Снимок — сборка **2026.10.07.01** (`6adc4c25`, тег выпуска), то есть ДО `37721287` (`AMBER211`).
В ней строки окна Measurement Result строились по СЕТУ: ключ строки — метка ряда из библиотеки
человека (`NuclideDefinition.Chain` или хвост имени в скобках), а компонент и предел разбора
искались по этому ключу ТОЧНЫМ сравнением строк (`FsaMeasurementResult.FindLimit` /
`FindComponent`). Библиотека Amber пишет имена без дефиса — «Th232», «Pb212 (Th232)» (видно в
окне «Обнаружение пиков» на снимке), а разбор называет ряд по базе — «Th-232». «Th232» ≠
«Th-232» → строка «в разборе нет», МДА 0, хотя сам разбор ряд нашёл (отчёт FSA: Ac-228 40.47 %
… — ряд Th-232). Состав при этом собирался верно: `DeclaredOf` приводит имя через
`FsaSampleLibrary.NucidOf`, а сличение строк окна — нет.

В master с `37721287` (`AMBER211`) строки окна берутся из самого разбора (имя компонента / корень
ряда), сличения с сетом нет — этого дефекта там уже нет. Нужен новый выпуск.

## Остаток, найденный при разборе, — исправлен (не закоммичено)

`FsaMeasurementResult.Line` брал период полураспада строки (поправка к дате отбора,
`MeasurementResultManager.Correct`) по определению библиотеки с ТОЧНО тем же именем. Имя строки
теперь — имя разбора («Th-232», «Tl-208»), и при библиотеке «Th232» определение не находилось →
период 0 → поправка на распад тихо выключена. Правка: нет определения с таким именем (или период
нулевой) — период из базы по `nucid` имени (`NucBaseFramework.HalfLifeYearsOf(NucidOf(name))`),
как у корня ряда в `NuclideDefinition.DecayHalfLifeYears`. В `FsaBqProbe` добавлен столбец
«T½ лет» — период строки, которым окно приводит активность к дате отбора.
