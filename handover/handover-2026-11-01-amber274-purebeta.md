# `AMBER274`, Э1: чистые бета-излучатели, сумма ветвей β, сверка `nucdb` с LNHB (01.11.2026, полоса `purebeta`)

Полоса распорядителя по строке `AMBER274`, три пункта Э1 — решения Amber 30.10.2026 вопросником (дословно — в
строке реестра и в журнале Э1 `handover/handover-2026-10-29-amber274-e1-sample-beta.md`):

1. чистые бета-излучатели (Sr-90/Y-90, Bi-210 без Pb-210) — **«Строка без линий по набору (Рекомендую)»**
   (находка Ф14 критика физики Э1);
2. ветви β без проверки суммы (К3 критика кода, «Критики несходимостей»: у 179 из 1640 нуклидов ΣIβ > 101 %);
3. расхождения `nucdb` с LNHB — **«Сверить и поправить по LNHB (Рекомендую)»** (её слово на запись в `nucdb`).

Работа — в worktree от снимка `refs/snap/tw1101` (Э1 + физика 28, не закоммичено в основном дереве);
временное — каталог полосы на D:. Сборки Release полосы: `Release_purebase` — снимок как есть;
`Release_purebeta`/`Release_purelnhb` — первый вариант правки с прежней и исправленной `nucdb` (контроли ниже);
`Release_pb2orig`/`Release_pb2lnhb` — окончательная правка (строка — только у ряда без настоящего излучателя;
доля своих распадов по бете) с прежней и исправленной `nucdb`; пробы — свои каталоги.

## 1. Строка по сплошному спектру (`Ф14`)

**Что было.** Колонка компонента FSA рождалась только от линий: член ряда без линий, но с бетой,
ложился в колонку ряда (`Р3`), а без хозяина получал заметку «бета X без линий — колонки нет». Y-90
к тому же «излучал» — следовая гамма 2186 кэВ (1.4·10⁻⁶ %) и K-линии (0.009 %), — и ряд Sr-90 давал
колонку «Y-90» на одной следовой линии; в окне фита без неё — пустой образ, выброшенный вместе с бетой.

**Что сделано.**

* Сборка состава (`FsaSampleLibrary.Build` → `BetaOnlyColumns`): строка по сплошному спектру
  (`FsaComponent.BetaOnly`) — у члена с бетой без хозяина (Sr-90 сам по себе, Bi-210 без Pb-210) и у
  колонки, чей фотонный выход ниже пола `PureBetaPhotonFloorPercent` = 0.01 % на распад (пол полноты самой
  базы, решение Amber 01.10.2026 по добору слабых гамм `AMBER151`; своего соглашения не заводилось).
  Следовые линии такой колонки снимаются, бета — всех её бета-членов тем же равновесным весом, что у линий.
  Группировка как у колонок с линиями: ряд Sr-90 при равновесии — одна колонка «Sr-90» вида ряда (Sr-90 и
  Y-90), без равновесия — по колонке на член. Выход `TotalYieldPercent` — NaN: правило `S69` строку не
  сворачивает. ⛔ Только ряд БЕЗ настоящего излучателя (ни у одного члена фотонный выход не достигает пола) —
  «Bi-210 без Pb-210» дословно: в ряду Ra-226 при выключенном равновесии Bi-210 тоже без хозяина, но ряд
  излучает, и Bi-210 там остаётся заметкой, как прежде. Поймано витриной: первый вариант правки ставил на
  радоновом фильтре (ряд Ra-226 без равновесия) строку «Строки по сплошному спектру сняты: Bi-210» —
  на каждом разборе без раздела; числа фита те же, строка отчёта — шум. Мерено по базе: Σ фотонов у Sr-90, Bi-210, P-32, C-14, H-3 — 0; Y-90 0.0095 %, Sr-89
  0.0096 %, Pm-147 0.006 %; ближайшие сверху — уже со своей гаммой: Cl-36 0.15 %, Tl-207 0.27 %.
* Разбор (`FsaAnalyzer`): без годного раздела электрона строка снимается ДО фита с причиной
  (`BetaOnlyRemoved`, `BetaOnlyRemovedReason`: матрицы нет / бета выключена / раздел не годен — чем,
  `SampleBetaRefusal` / канал снят маской); длину образа задаёт бета (`BuildResponseDeposit`); «пиковые
  отсчёты» строки — весь её образ в полосе (окон ±2 ПШПВ у неё нет, иначе предел печатался бы «< 0 %»);
  гейт формы её не судит (пиковой зоны нет); пределы — тем же правилом ISO 11929, что у прочих.
  Состав опустел снятием — к отказу «библиотека опустела» приписка с именами и причиной.
* Отчёт FSA (`FSAReportView`, слова — `FSAReportView.resx`/`.ru.resx`, en первичен): у строки состава и
  у строки предела — «— по сплошному спектру» / «— by the continuum» (`RowCaption`); в блоке качества —
  «Строки по сплошному спектру сняты: Sr-90 — у матрицы отклика нет раздела электронов; пересчитайте её
  со слоем «Бета пробы»» (и прочие причины); окно результата (`DCResultView`, ключ

* Имён нуклидов в коде нет: кто чистый излучатель — говорит база.

## 2. Сумма ветвей β (`К3`)

`FsaBetaLibrary.Read`: строки-пределы `LT`/`LE` (`intensity_unc`) отбрасываются всегда; при Σ > 100 % +
`BranchSumTolerancePercent` (1 %) отбрасываются дубли второй оценки — пара одного вида с границей в
max(5 кэВ, 2 %) и выходами в 1.25 раза, берётся строка, стоящая раньше в поставке (`dr_pk`); остаток выше
101 % — `FsaBeta.BranchSumPercent`, и отчёт FSA называет нуклид, чья бета легла в образ («Ветви β в базе с
суммой выше 100 %: …», блок качества). Порядок прочих строк не меняется — у нуклидов без пределов и дублей
образ тот же до бита (малая база выше). Две близкие ветви бывают честно: у `234PA` 472 кэВ — уровни 1722.9
и 1723.45 кэВ (12.4 и 33 % по ENSDF), выходы разные, — условие на выход их не трогает.

| нуклид | было | стало |
|---|---|---|
| Pa-234 | 30 строк, Σ 129.47 % | 9 пределов `LT` (24.6 %) отброшены, Σ 104.87 % — в отчёт |
| Ra-225 | 4 строки, Σ 200 % (два набора: 68.8 + 31.2 и 69.5 + 30.5) | дубли второго набора не сложены, Σ 100.0 % |
| Fr-223 | Σ 98.8 % | 2 предела `LE` (2 %) отброшены |

По всей базе (до правки LNHB): Σ > 101 % у 179 нуклидов из 1617 с ветвями; без пределов — 71; без дублей —
50 (почти все короткоживущие; в рядах корпуса — Pa-234 104.87 %, Tl-210 103.0 %, Pa-233 101.7 %).

## Что не сделано и почему

* ⛔ Несходимость положительного контроля поверх Cs-137 (выше) — по правилу Amber критикам; правка — шаг
  узлов сплайна или его штраф у строки по сплошному спектру — развилка постановки, полоса её не решала.
* Предел необнаруженной строки по сплошному спектру оптимистичен: без впрыска 9.99 Бк, а впрыск 100 Бк не
  виден, и предел при нём — 103…106 Бк. Предположение (опытом НЕ проверено): правило пределов (`S9`) судит
  коллинеарность только с АКТИВНЫМИ колонками фита, а шапки сплайна, прижатые NNLS к нулю (на этом спектре
  образ Cs-137 выше данных в полосе беты), в проекцию не входят; у линий это мелочь, у сплошной беты —
  множитель ~10. Правка правила затронула бы все строки — развилка распорядителю.
* Гамма-выходы Ac-228 (87 из 95 линий ≥ 0.05 % расходятся с LNHB больше 1 %: 911.2 25.8 → 26.2 %,
  338.32 11.27 → 11.4 %…) и Pa-234m (1001.03 0.842 → 0.847 %, 766.4 0.317 → 0.323 %, 742.8 0.1066 → 0.094 %) —
  в решении Amber их нет, не правились.
* Pb-212 415.2 кэВ: LNHB (2025) 0.013 % против NuDat 0.1439 % — в 11 раз; взято по LNHB, как решено.
* Строка через путь «По меткам найденных пиков» (`FsaLibrary.BuildFromPeaks`) беты не несёт вовсе (известный
  дефект, решение Amber «Решить позже»): чистому излучателю пика нет, и туда он не попадает по построению.
* RC103_Cs137_0cm на складе физики 28 с точкой ОСГИ даёт 6624.7 Бк при паспорте 5564 (×1.19) — сдвиг склада
  (`Ф6`), не этой полосы; общий счёт.
