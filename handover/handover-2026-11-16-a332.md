## Что сделано

* **Один источник веществ.** Наполнение списка веществ редактора вынесено в `GeometryMaterialLibrary.ForSlot(kind)`
  (свой вид, у стенки — ещё металлы корпуса, потом «прочие»); `GeometryEditorPanel.FillMaterialCombo` берёт строки
  оттуда же — поведение редактора прежнее. Список окна импорта берёт `ForSlot(MaterialKind.Source)` — ровно строки
  «Проба» вкладки «Источник» (проба сверяет поимённо: 282 из 282 в том же порядке).
* **Блок «Сопоставление»** (`GdmlMappingPanel`, один элемент в окне импорта и на подвкладке «Файл GDML»): под списком
  деталей пробы — подпись «Вещество пробы из редактора геометрии» / «Sample material from the geometry editor» и список;
  первая строка «(из файла)» / «(from file)». Список доступен, когда галка «и образец» стоит и деталь-проба выбрана;
  подсказка: заменяется только вещество, форма, размеры, сосуд и положение — из файла. Выбор вещества помечает образец
  «выбрано вручную» и оживляет «Пересчитать».
* **Выбор и раскладка.** `GdmlChoice.SampleMaterial` (null — из файла); `Same` сравнивает вещество (имя, плотность,
  состав — `GdmlChoice.SameMaterial`), `Clone` его несёт, `Build` передаёт в новую перегрузку
  `GdmlFieldMap.Build(..., sampleMaterial)`. В раскладке меняется только `g.Source`; прочее (`LaySample`) — из файла.
  `GdmlFieldMap.SampleMassG` — масса пробы в полях: собственный объём детали-пробы (как у читателя, без вложенных) на
  плотность вещества полей; «из файла» — масса детали файла.
* **Что видит человек.** Сверка «в файле → в полях» — новая строка «Вещество пробы WATER, 392 г → Silicon dioxide из
  редактора, 1.6 г/см3, 627.2 г»; легенда чертежа — «Проба: Silicon dioxide, 627.2 г» (`GdmlSketchMarks.SampleMaterial`,
  `SampleMassG`; если вещество файла есть и у других деталей, они остаются своей строкой без роли); строка-итог окна
  импорта — «Вещество пробы из редактора: …, плотность, масса». При «(из файла)» ни одна из этих строк не появляется.
* **Сохранение.** `GdmlImportInfo.SampleMaterial` (атрибут, пишется только непустым): имя вещества. При открытии кривой
  вещество берётся из сохранённых полей (`FromInfo(..., config.Geometry.Source)`), нет совпадения имени — из библиотеки
  по имени, нет и там — вещество файла, и сверка полей при открытии говорит о расхождении. Запись без атрибута (все
  кривые до `AMBER332`) читается как «(из файла)»; «(из файла)» атрибута не пишет — XML прежний.
* **Тексты** — `Properties/Resources.resx` и `Resources.ru.resx`, шесть ключей: `GdmlMapFromFile`,
  `GdmlMapSampleMaterial`, `GdmlMapSampleMaterialTip`, `GdmlMapSampleMaterialFile`, `GdmlMapSampleMaterialEditor`,
  `GdmlSampleMaterialNote`. Подпись сначала была «…from the editor's list»; апостроф рвал строку JS гида —
  заменена на «from the geometry editor» / «из редактора геометрии».
* **Гид** `docs/geometry.html`: подпись окна импорта (`m.gdlg`, ru и en) — одна фраза о новом списке. Снимки
  `effmaker-gdml` и `effmaker-gdml-import` (ru, en) пересняты конвейером `tools/guide_shots/shoot.ps1 -Shots
  effmaker-gdml,effmaker-gdml-import -Build -Install -Work D:\BqMoni_Claude\a332\guideshot` (код 0, отказов 0); блок
  стал на 45 точек выше — точки `data-hot` поправлены: окно импорта — прямоугольник «Сопоставление» по высоте 0.3765 →
  0.4661; подвкладка — «Сопоставление» 0.3118 → 0.3646, сводка y 0.4971 → 0.5499, высота 0.4267 → 0.3740 (сдвиг 45
  точек найден сравнением строк прежнего и нового снимка; прямоугольники проверены наложением). Заливку на сайт делает
  распорядитель.

## Вердикт критика `crit332` и две дочинки (16.11.2026)

Критик принял работу по всем десяти пунктам и нашёл две мелочи; дочинены в этой же полосе.

1. **Пропавшее вещество называется по имени.** Вещество пробы из записи, которого нет ни в сохранённых полях, ни в
   библиотеке веществ, раньше молча становилось «(из файла)», а общая строка `GdmlSavedDiffers` его не называла.
   Теперь `GdmlChoice.FromInfo(..., savedSource, missingMaterials)` (`GdmlImportUi.cs`) собирает такие имена, а
   `EfficiencyMakerForm.AttachSavedGdml` кладёт в сводку и журнал строку нового ключа `GdmlMapMaterialMissing`: «Sample
   material {0} is neither in the saved fields nor in the material library: the list shows “(from file)”. The fields are
   as saved.» / «Вещества пробы {0} нет ни в сохранённых полях, ни в библиотеке веществ: в списке «(из файла)». Поля —
   как сохранены.» Общая строка «поля расходятся» остаётся рядом.
2. **Список перезаполняется после правки библиотеки.** `GdmlMappingPanel.RefillMaterials()` перестраивает список
   вещества пробы (`FillMaterials`, общий с `SetFile`) и ставит прежний выбор тем же веществом, ничего не сообщая и не
   трогая поля; `GeometryEditorPanel.ApplyLibraryEdit` зовёт его вслед за своими списками.

Проба, плечо О дополнено (О.4, О.5) и двумя порчами: `--only=a332` — «СОШЛОСЬ», 115 проверок, код 0; полный прогон с
`--data=..\data\gdml_a303` — 211 проверок, код 0. Порча: `drop` — 22 отказа из 115, `part` — 29, `lostname` (в записи
вещество, которое в библиотеке есть) — 1, `norefill` (путь после окна библиотеки не пройден) — 1; у всех код 1.
