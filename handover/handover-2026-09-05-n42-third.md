## `A157`. Отказ разбора даты назван — по замеру СДЕЛАНО

Пустого `catch { }` в разборе 2012 года больше нет; отказ считается, первая негодная
запись запоминается, и голос звучит ОДИН раз на файл.

| вход `case16_baddate` (дата по хиджре `04/05/44 10:07:57 ص`), `en-US` | «до» | «после» |
|---|---|---|
| приговор | ВВЕЗЁН | ВВЕЗЁН |
| сказано человеку | **(молча)** | «The start time of the measurement could not be read in 1 measurement(s) of the N42 file (first one: 04/05/44 10:07:57 ص — FormatException); the current time is used instead. Everything else in the spectrum is imported.» |

⚠ **Положительный контроль на месте:** под `ar-SA` та же дата ЧИТАЕТСЯ (запасная
попытка `CurrentCulture` в `ParseMeasurementStartDateTime`), приговор ВВЕЗЁН и голоса
НЕТ. То есть голос звучит ровно тогда, когда дата действительно потеряна, а не по
факту нестандартной записи.

Решение «ввозить, сказав вслух, а не отказывать» перепроверено по коду и признано
верным: соседние ветви того же файла бросают из-за негодной ЭНЕРГЕТИЧЕСКОЙ ШКАЛЫ, по

### ⛔ ЧЕСТНО: цена пяти мест из шести — НОЛЬ, и я это перемерила сама

Замер по ВСЕМ культурам **в среде приложения** (проба на .NET Framework 4.8, NLS,

| выражение | отказ | иное значение |
|---|---|---|
| `int.Parse("-3")` без культуры | **0** | **0** |
| `int.Parse("12345")` без культуры | **0** | **0** |
| `double.Parse("3.5")` без культуры | **234** | **179** |

среде культурно-независимо фактически, и пять мест `int.Parse` — это ПРАВИЛО, а не
исправление числа; положительного контроля им не бывает вовсе. Настоящая цена есть
только у `double.Parse` (413 культур из 915), и живёт она в
`EnergyCalibration.CoefficientsToArray`, **у которого читателей в дереве НОЛЬ** —
проверено сплошным поиском по имени во всём дереве, единственное вхождение это само
объявление.

качественно ложно для приложения.** PowerShell 7 — .NET 8 с ICU (890 культур),
приложение — .NET Framework 4.8 с NLS (915 культур). Обе цифры сняты мной в один

икушное число («у 41 культуры из 890 знак минуса не дефис, например sv-SE») фактом о

## Готовый текст для закрытия строк

* **`A154`** — ключ `PeakFitChiTableScoreColumn` заведён в оба resx и в `Designer.cs`;

  культурах, у новой — «AIC (chi2 + parameter penalty)» / «AIC (chi2 + штраф за
  параметры)», при работающих положительном и отрицательном контролях.
  `check_resx_designer.py` по этому разряду: находок 0.
* **`A157`** — пустой `catch { }` в разборе 2012 года снят; отказ разбора даты
  считается и говорится ОДИН раз на файл, спектр при этом ввозится (время начала
  паспортное и ни в одно вычисление не входит). Измерено на входе с датой по хиджре:
  «до» — молча, «после» — назван и текст записи, и род отказа. Под `ar-SA` та же дата
