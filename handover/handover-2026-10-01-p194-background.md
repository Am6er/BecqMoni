## 1. `AMBER141` — подложка ниже нуля в меру шума вычтенного фона

**Правка.** Шапки континуума решаются с нижней границей `c_j ≥ −L_j` вместо `c_j ≥ 0`,
только когда фон вычтен (без фона — побитово прежнее). Решатель тот же NNLS: сдвиг
переменной `c′ = c + L`, правая часть `c + G·L` по штрафованной Грам (штраф на излом — по
истинным коэффициентам), после решения сдвиг снимается (`FitOnce`). Шапки ниже нуля
доезжают до модели, до подложки опор и до `FsaResult.Continuum` (три места `<= 0` → `== 0`;

## 2. `AMBER154` — хранимый фон в истинной шкале пробы

**Правка.** `Analyze` стал обёрткой над прежним телом (`AnalyzeOnce`):

1. Первый проход — как прежде (фон в объявленной шкале).
2. `MeasureBackgroundGain`: остаток D = данные − (модель − подложка) первого прохода (образы
   пробы вынуты, остались комнатный фон в истинной шкале пробы и подложка) против хранимого
   фона B, растянутого по номеру канала на g (`StretchedCalibration`: отсчёт из канала p — в
   g·p). Оба сглаживаются гауссом σ = ½·σ_пика, затем вторая разность с шагом ПШПВ;
   усиление — Гауссом — Ньютоном `f(D) ≈ a·f(B_g) + c·(−p·∂f(B_g)/∂p)`, `g ← g(1 + c/a)` до
   сходимости. Мерится РАЗНОСТЬ шкал двух съёмок, не привязка пробы (абсолютное усиление
   привязки несёт модель света и растяжение ≈ 1 % и без дрейфа — его брать нельзя).
3. Неподвижная точка, не одна мера: когда пик фона на той же линии, что у пробы (K-40 в
   пробе с K-40), привязка первого прохода сдвинута несведённым фоном, и первая мера
   недодаёт (у `G1S24_K40_Petri_2` при дрейфе 1 % — 0.58 %). Второй проход — по первой
   мере, третий — секущей по двум; не больше трёх проходов разбора.
4. **Арбитр — χ²/ndf разбора**: проход с переложенным фоном принимается, только если χ² не
   хуже. Это и есть защита от меры, поймавшей остатки образов вместо дрейфа:
   `G1S24_Rn222Coal_Mar_eq01` мера +0.18 ± 0.10 % у пика 1481 кэВ среди линий Bi-214 пробы,
   перекладка подняла бы χ²/ndf 1.459 → 1.637 — отвергнута; `AS80_Lu176` −0.48 ± 0.06 % —
   отвергнута тем же.
5. Служебная строка (`FsaResult.AnchorNote`, по-русски, не для экрана): «фон: дрейф фона
   против пробы ±x % ± σ (z; у E кэВ ±n кан., ±e кэВ); …» по каждому проходу и итог
   «→ фон вычтен в шкале пробы, усиление g» / «→ фон вычтен в объявленной шкале»; поле
   `FsaResult.BackgroundGain` (1 / g / NaN — не измерен).

Перекладка фона в проходе с g ≠ 1 — тем же `Rebin`, приёмник `StretchedCalibration(калибровка
пробы, g)`; при g = 1 ветка прежняя побитово. Пол полосы, рампа порога и пороги АЦП по фону
не тронуты (низ шкалы растяжением почти не двигается). Ключ `BackgroundFollowsSample`
(умолчание ВКЛ). Пороги: значимость пиков фона в остатке z ≥ 5 (10 резал по живому: у
`G1S16_K40_Mar` истина z 10.0, её копия z 7.8), мёртвая зона 0.005 % (0.02 % оставляла
+0.18 % K-40 у слабой пробы), окно ±3 %. Порога значимости у самой меры нет нарочно: 2σ
(промежуточный вариант) у копии `G1S24_Ra226_Petri` (−0.245 ± 0.126 %) не перекладывал фон,
χ²/ndf 0.131 против 0.03, — судит χ².

Прибор: `BackgroundGainTraceSink` (каждый шаг Гаусса — Ньютона), ключ `--bgtrace` у
`FsaClosureP191`.

**Идемпотентность прохода** проверена до включения: временная сборка, где `Analyze` звал
прежнее тело дважды подряд, дала на малой базе `runs.csv` побитово те же числа (различались
