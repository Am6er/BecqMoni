## 3. Правка

### 3.1 Схема (`ElectronTransport.cs`, шапка раздела `M13` в коде)

Класс II по упругому рассеянию (как у PENELOPE), только в `TransportInLayers`, только под `ElectronLayerTransport`:

* отсечка μ_c = 1 − cos θ_c, θ_c = `LayerHardCutoffDeg` (20°; поле-рычаг замера, как `ElectronStepFraction`, в клеймо не входит);
* элементы слоя (`LayerScatterElements`, кэш на вещество): Z, ядер/см³ из массовых долей и `MaterialDatabase.AtomicMass`, Z(Z+1);
* на каждом шаге (`LayerElasticStep`, энергия начала шага): Σ n_i σ_i(μ > μ_c) с мажорантой Мотта 1 + παZβ/4 — обратный свободный
  пробег до кандидата жёсткого столкновения, доли элементов; транспортное сечение ниже отсечки Σ n_i ∫₀^{μ_c} μ dσ_i;
  dσ/dμ = 2π Z(Z+1) r_e² (mc²)²/(β²p²c²) / (μ + 2A)², 2A = 2(ħ/2pa)²(1.13 + 3.76(αZ/β)²), a = 0.885 a₀ Z^(−1/3);
* расстояние до жёсткого столкновения — экспонента; выпало раньше конца шага (0.1 пробега) — шаг укорачивается до него, мягкий шарнир
  считается на укороченный шаг, поворот жёсткого — в конце шага при энергии его конца (`LayerHardCollision`: элемент по доле, μ
  обращением ∫dμ/(μ+2A)² выше отсечки, отбор Мак-Кинли—Фешбаха R = 1 − β²s² + παZβ s(1 − s), s = sin(θ/2), для Z ≤ 30; отвергнутое —
  пустое столкновение); граница области раньше — переход без столкновения, как было;
* мягкий шарнир — прежний `SampleHingeMu`, ширина θ₀² = 1 − exp(−s·Σnσ_tr,soft) — средний 1 − cos θ мягких столкновений на длину шага;
* без ключа — ни одной новой ветки и ни одного нового случайного числа (побитовость §4.1). Счётчики `CountLayerSteps`,
  `CountLayerHardCollisions` (печатает `G4RawProbe`, `LayerReturnProbe`).

### 3.2 Две редакции мягкой ширины — почему не «Хайленд × √f_soft»

Строка предлагала уменьшить ширину Хайленда на долю транспортного сечения выше отсечки (редакция А). Замер (`tables/lr_variantA_*`,
RC103 П55, нормальное падение, 50 тыс.): А даёт ВКЛ лишь +12 % к ВЫКЛ (0.070/0.050/0.036 при 100/500/1000 кэВ), и **обе схемы не
сходятся по шагу** — при `--step` 0.1 → 0.05 → 0.02 → 0.01 η ВЫКЛ падает 0.062 → 0.049 → 0.034 → 0.027, А — 0.070 → 0.067 → 0.062 →
0.056. Причина: формула Хайленда НЕ аддитивна по шагу — логарифмическая скобка (1 + 0.038 ln(x/X₀β²)) при дроблении шага теряет вклад
хвоста, сумма гауссовых ядер тонких шагов уже одного ядра толстого. Транспортное сечение аддитивно по построению (⟨cos⟩ перемножается):
редакция Б (принята) даёт 0.0722/0.0533/0.0389 при 0.1 и 0.0741/0.0555/0.0415 при 0.01 (+3…7 %, `tables/lr_step_*.txt`). ⚠ Отсюда же
следствие для ВЫКЛ (физика 19): η слоя при шаге 0.1 — не сходившееся число, а свойство шага; в кристалле шаг 0.1 поверен П27 по пику и
не трогается.

Независимость от отсечки (`tables/lr_cutoff_*.txt`, PTFE толстая, 100 тыс.): 10° 0.0719/0.0543/0.0393, 20° 0.0722/0.0533/0.0389,
30° 0.0701/0.0530/0.0381, 45° 0.0683/0.0514/0.0374 (жёстких на шаг 0.69 → 0.26 → 0.12 → 0.05) — ±5 %, схема самосогласована. Поправка
Мотта при 500 кэВ гасит рассеяние назад в 4 раза (R(180°) = 1 − β² = 0.26) — это физика, не схема; недобор к арбитру — не в делении.
