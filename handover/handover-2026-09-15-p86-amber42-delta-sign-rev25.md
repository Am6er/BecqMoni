## 1. Диагноз и литература

Наш `For` считал оба перехода каскада одной формулой `A_k = [F_k(L,L,j′,j) + 2δ·F_k(L,L′,j′,j) + δ²·F_k(L′,L′,j′,j)]/(1+δ²)`
с j = промежуточный уровень (дважды в 6j). Для СНИМАЮЩЕГО перехода (j′ = J_end, j = J_mid) это и есть коэффициент
Кране–Стеффена A_k(L,L′,J_i,J_f) с J_i = J_mid; для ЗАСЕЛЯЮЩЕГО (j′ = J_start, j = J_mid) — параметр ориентации
B_k(L,L′,J_f,J_i), и в соглашении Кране–Стеффена (в нём даны δ ENSDF и PhotonEvaporation = `g4_gamma.mixing_ratio`)
его интерференционный член несёт (−1)^(L+L′):

* Krane, Steffen, Phys. Rev. C 2, 724 (1970); Krane, Steffen, Wheeler, Nucl. Data Tables 11, 351 (1973) — соглашение;
* arXiv:2110.00619 (Monte Carlo γ-корреляций по статистическим тензорам, 2021), ур. (9) `A_λ = [F + 2δF′ + δ²F″]/(1+δ²)`
  и ур. (12) `B_λ = [F + (−1)^{L+L′}·2δ₀F′ + δ₀²F″]/(1+δ₀²)`, с оговоркой дословно: «the right-hand side of the
  expressions in Eq. 9 and Eq. 12 are not entirely identical, but they differ by a phase factor (−1)^{L+L′}»; там же
  контроль a₂ = B₂(2,3,2,4,0)·A₂(2,2,2,0,0) = (−0.171)·(−0.598) = 0.102 — наш учебный Co-60;
* Geant4 11.4.2 `G4PolarizationTransition.cc`: `FCoefficient(K, L, L′, 2J₂, 2J₁)` с J₁ (излучающий) дважды в 6j и
  фазой (−1)^{J₁+J₂−1}; первый переход идёт через F3 (9j) статистических тензоров — итог П85 измерила: совпадает с нашей
  симметричной формулой при `−δ₁`.

Правка — `delta1 = ((l1 + l1Prime) % 2 != 0) ? -mixing1 : mixing1` (общий вид; у всех смешанных переходов базы L′ = L ± 1,
то есть ровно `−δ₁`, как предлагала П85). Чистые каскады (δ = 0) не тронуты; A₄₄ ∝ δ² — не меняется.
