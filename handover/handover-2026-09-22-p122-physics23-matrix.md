## 3. `AMBER57` — наклон F² в последнем отрезке розыгрыша рэлея

### 3.1 Посылка по коду — верна

`ScatteringData.Atom.SampleMomentumTransferSq`: `i ≤ last ≤ n − 2`, при `i == last` бралось `t1 = tMax`, `dt = tMax − t[last]`, а
`b = f2[last + 1]` — значение в узле ЗА `tMax`; `slope = (b − a)/dt` завышен в `(t[last+1] − t[last])/(tMax − t[last])` раз, тогда как
`head = PartialIntegral(…)` (вес отрезка) считан по полному отрезку. Квадратное уравнение решалось для чужой плотности; при
F² убывающей завышенный наклон даёт бóльшую Δ, зажим `delta > dt` сажает розыгрыш на `t = tMax` → cos θ = −1.
