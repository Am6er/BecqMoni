### (3) Менеджер поставки при `--sample=` не поднимается пробой — и подложен пустым одиночке

Своих обращений у пробы при `--sample=` больше нет: `nuclides` = null, первый `DetectPeak`
с `nuclides.ActiveSet` (его результат при `--sample=` всё равно выбрасывался) не зовётся;
`SETUP найдено пиков: N (подписи из базы)` печатается после поиска с подписями из библиотеки.

⚠ **Одной ленивости мало — менеджер зовёт код ПОКАЗА приложения.** Измерено в этой полосе
(`--spoil=manager` без файла, лог `control_gate_spoil_manager_without_file_Mar.log`): после
снятия строки 207 проба падает тем же `InvalidOperationException` в `WithReport` →
`FsaAnalysisSession.BuildStamp` → `NuclideSetStamp()` → `NuclideDefinitionManager.GetInstance()`
(безусловно, без окон бросает). Отпечаток сеансу нужен: без него окно отчёта
(`Consume` → `EnsureUpToDate` → тот же `BuildStamp`) сочло бы подложенный результат
устаревшим и заказало бы СВОЙ счёт. Конструктор `EnergySpectrumView` зовёт менеджер тоже
(`TryLoadRuntimeDependencies`, исключение глотает, счётчик растёт).

Поэтому при `--sample=` ДО первого обращения одиночке `NuclideDefinitionManager.instance`
подкладывается ПУСТОЙ список, помеченный загруженным (`PrimeEmptySuppliedLibrary`:
`new NuclideDefinitionManager { NuclideDefinitionFile = new NuclideDefinitionFile() }`,
`isLoaded = true` отражением) — ровно то, что приложение делает для вида
(`EnergySpectrumView.CreateNuclideDefinitionManagerFallback`). `GetInstance()` после этого
файл не открывает и не бросает; кто бы ни спросил — получает ноль определений, ноль наборов,
и состав снимка взять из поставочной неоткуда. Строки `nuclide library: …: N entries` в
логе нет — файл не читался (см. логи `*_after.log`).

**Гейт `AMBER19` (`SuppliedLibraryGate`, в конце всегда).** У восьми проб оснастки (П11) гейт
судит счётчик обращений (`RaiseCount` > 0 → код 12); здесь счётчик при `--sample=` НЕ ноль
по праву (2 обращения кода показа, см. выше), и это не обойти без правки приложения. Судится
поэтому не число обращений, а ЧТО они получили: одиночка обязана остаться пустышкой —
ноль определений и ноль наборов; список с определениями при объявленном составе → код 12
«⛔ AMBER19: при --sample= поставочный список поднялся с N определениями…». Без `--sample=`
(подписи, `--infer`) список нужен по праву — гейт печатает счётчик и не судит.

Положительный контроль гейта — ключ `--spoil=manager` (как у `CorpusFsaProbe`): пустышка не
подкладывается. С поставочным файлом рядом список поднимается настоящим (143 определения)
→ гейт даёт **код 12** (`control_gate_spoil_manager_with_file_Mar.log`); без файла — падение
до счёта, как у пробы до `T257` (3) (`control_gate_spoil_manager_without_file_Mar.log`, PNG
не создан).

## 5. Факты и находки — по §9

* **Код показа приложения поднимает менеджер поставки безусловно** (`FsaAnalysisSession.NuclideSetStamp`
  → `GetInstance()`; конструктор `EnergySpectrumView` — с проглатыванием). В приложении это
  не дефект — там менеджер всегда поднят панелью; для проб без поставочного файла это значит,
  что гейт «обращений 0» у снимковых проб недостижим, и пустышка одиночке — единственный
  путь без правки приложения. Запись факта, строки не завожу (приложение — только читать;
  для человека за экраном ничего не меняется). Если понадобится строже — правка в
  `NuclideSetStamp` («менеджер не поднят → "all"») в один вызов, решение за Amber.
* `tools/effmaker/probes/README.md` §`FsaStackShot.cs` устарел: нет `--sample=`, `--scale`,
  `--select`, `--huber`, `--spoil=manager`; упомянут снятый `--no-room`. Файл в дереве
  правится другой полосой (незакоммичен), поэтому не тронут — назвать распорядителю; правка
  дешевле получаса, строки не завожу.
* Две «поставочные» копии `NuclideDefinition.xml` расходятся: `config/` дерева — 143 записи,
  каталог проб (`build_all.ps1`: «152 записей, sha 7aaa0b01c9bd») — 152. На числа полосы не
  влияет (при `--sample=` файл не читается вовсе). Поставочные — по приказу 05.09 не
  принимается.
* П47 правила `FsaAnalyzer.cs` и `CorpusFsaProbe.cs`/`FsaP42ArmProbe.cs` под чужими сборками
  (17:01, 17:02, 17:10): сторож каталога проб (`T41`/`T226`) отказывал верно, цена — два лишних
  цикла сборки у соседней полосы. Факт, в журнал; к концу полосы П47 закоммичена (`72388995`).
