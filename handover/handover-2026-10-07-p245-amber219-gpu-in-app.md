# П245, 07.10.2026 — `AMBER219`: галка «Use Nvidia GPU» и счёт матрицы отклика на GPU в приложении

## Постановка

Amber, консоль со снимком окна «Response matrix», дословно: **«Форма расчёта матрицы отклика.
Этой галки уже нет. На её место добавить галку "Use Nvidia GPU". Расчёт корпуса по GPU уже
есть, то есть алгоритм рабочий. Просмотри его на качество и добавь возможность считать на GPU
в приложение. Но учти, не у всех может быть установлен CUDA (тут я не уверен - она вообще нужна
для расчёта на GPU?), не у всех видео карта Nvidia. Это нужно сразу учитывать при открытии
формы, чтобы не было ошибок. Если критерии расчёта не удовлетворяют - галка недоступна к выбору
и ToolTip с объяснением, причины. Значение галки по умолчанию - выключено. Текущая настройка
запоминается глобально в приложении.»**

Разбор навыком `analyst` до правки. Что установлено по дереву и машине:

* **CUDA Toolkit пользователю не нужен.** `rmgpu_f.dll` слинкована со статическим рантаймом
  CUDA: `dumpbin /dependents` — единственная зависимость `KERNEL32.dll`. Нужны карта NVIDIA и
  её драйвер (`nvcuda.dll`), не старее рантайма 12.8, под который собрано ядро.
* Ядро собрано под `sm_86` (RTX 30xx); 40xx/50xx исполняют PTX через JIT драйвера при первом
  запуске, карты старее ядро не запустят.
* GPU-путь (`AMBER160`/`AMBER161`, П221/П227) считал только плоско (`ContinuumErrorTarget = 0`),
  так считается и склад rev46 (`--gpu --target=0 --n=3000000`); CPU-путь приложения по
  умолчанию останавливается по шуму 3 %.
* DLL в git не было (`tools/effmaker/gpu/bin` не отслеживается); C#-часть порта жила в пробах и
  читала закрытые члены симулятора отражением (решение «Только оснастка» 02.10.2026).
* TDR Windows (2 с на ядро) на этой машине не поднят; аналоговая ветвь верхних узлов на 3 млн
  историй одним запуском к порогу подходит даже на RTX 3070.

**Решения Amber 07.10.2026 вопросником, дословно:**

| вопрос | ответ |
|---|---|
| останов по шуму при галке GPU | **«Плоско, как склад»** |
| какие карты поддерживать сборкой | **«RTX 30xx и новее»** |
| где жить `rmgpu_f.dll` для поставки | **«В git, как SpecUtilsNet.dll»** |
| отражение в C#-части порта | **«Перевести на прямой доступ сейчас»** |
