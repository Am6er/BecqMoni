## 2. `AMBER294`: при тормозе нет «+», причина на экране

Amber 05.11.2026 вопросником, дословно: **«Показать причину, снять «+» (Рекомендую)»**; текст строки: **«Шкала не подстроена (Рекомендую)»**; строка для карты света: **«Своя строка для карты (Рекомендую)»**, **«Только нелинейность (Рекомендую)»**.

Тормоз усиления (`AMBER269`, (А1)) останавливал проход, но `Used` у опоры оставался: окно рисовало «+» при итоге «опор 0, усиление
1.0», и причины на экране не было. На экран теперь выводится итог; служебная `AnchorNote` с «опор 1 … усиление a 1.07332» не
менялась, читателя в окне у неё нет.

* `FsaAnalyzer.MarkBrakedAnchors` зовётся после цикла привязки, при `movedBy == 0` и сработавшем тормозе: `Used` снят,
  `Refusal` = `FsaScaleAnchor.RefusalGainBrake`. Внутри цикла `Used` судит тормоз и шаг шкалы, поэтому на числа разбора отметка
  не влияет. Тормоз на позднем проходе и на тёплом старте, когда шкала уже сдвинута, не отмечается, §5.
* `FsaResult.AnchorBrakedPeaks`, `AnchorBrakedTopKev`, `AnchorBrakeZeroMaxKev`; при откате переносятся с отменённого разбора.
  `AnchorBrakedTopKev` — центр модели верхней по линии опоры: то же число, что в строке этой опоры в подсказке
  (`AS80_Cs137_0cm`: было 1408.0 в подписи и 1420.2 в подсказке, стало 1420.2 в обеих).
* `FSAReportView`: строка опор «нет», красная строка причины, значение «не подстроена», в подсказке «-» и слова вместо служебного
  `brake`, своя шапка вместо «по которым подстроена шкала». При тормозе с откатом строка «подстройка по 0 пикам (+0.00 %)» заменена:
  подстройки не было; значение и там «не подстроена».

Почему не «шкала файла» (находка критика): на `G1S16_K40_Mar`, порог 2000, с матрицей без отката карта света двигает шкалу: β 1,
`AdcScale` 1.0405, `AdcE0Kev` −19.34. При откате (`AS80_Cs137_0cm`, порог 3000) `AdcScale` 0, карты нет, но слово то же, чтобы значение
не зависело от ветви. Из подсказки снято «шкала осталась как в калибровке файла».

Ветка карты (`FSAReportView.AnchorBrakeOnMap`: снятые опоры есть, отката нет, `AdcScale` больше нуля): усиление стоит, а карта света
движется. Своя строка, значение и подсказка без утверждения про неподвижную шкалу.

Строка отката при тормозе и при нуле опор у отменённого разбора — «Подстройка шкалы ухудшила подгонку»: ухудшила карта шкалы, а не поиск
опор (`AS80_Cs137_0cm`, порог 3000: отменённый разбор усиление 1, опор 0, `AdcScale` 1.0415, `AdcZeroKev` 0.21, χ²/ndf 89.13; с
`--zero=calib` ровно 83.986, замер второго критика). Ветка «по N пикам» (`AMBER284`, слово Amber) осталась для N больше нуля. Ветка при
N = 0 без тормоза прежде печатала «по 0 пикам (+0.00 %)»; значение строки там осталось «шкала файла»: отдан разбор без карты.
