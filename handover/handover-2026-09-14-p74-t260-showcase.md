   нет `FsaStackShot.exe`/`BecquerelMonitor.exe`/`.appwd.json` — код 3.

   `Get-AppWdStampSources`, `Compare-AppWdSourceMap`, `Get-AppWdSha256`; своей копии отпечатка нет):
   набор приложения по `.csproj` и набор `FsaStackShot` (её `.cs` + 5 довесков) против заверения,
   sha `BecquerelMonitor.exe` рядом с пробами и `FsaStackShot.exe` против заверённых, плюс
   `repo` в заверении = это дерево. Приговор нарочно СУЖЕН до того, что сторож исполняет
   (чужая проба соседа каталог не протухает — сам `T226`). Протухло — код 3 с находками; 0.7–2 с.
   `--skip-freshness` — только стенд полосы; эталон git с ним не пишется (проверено: отказ кодом 3,
   пишет только в сторонний `--reference=`, и говорит об этом).
3. **Рабочий каталог** `tools/fsa_showcase/wd/`: зеркало каталога проб (без его `config\device` и
   `config\NuclideDefinition.xml`; изменившееся по размеру/времени копируется, лишнее снимается) +
   конфиг витрины (библиотека, приборы РОВНО витрины — лишний прибор снимается, `T33`) + матрицы под
   guid узла `<Efficiency>` каждого спектра (`store:` → склад витрины, `corpus:` → живой склад корпуса,
   `.qk` рядом; `none` — ничего). Нет матрицы/спектра/конфига — код 2 с именем и подсказкой.
4. **Прогон** `FsaStackShot --spectrum=… <ключи режима> --screen --scale=pow --width=1600 --dump= --rates=
   --out=` из `wd`; отказ пробы — код 2 с её хвостом. Выходы — `wd/out/<пара>.{log,curves.csv,rates.csv,png}`
   (PNG — для глаз при отказе).
5. **Свёртка**: дамп по каналам → по полосам: Σ `net` (показная), `model`, `fit` (кривая фита), `continuum_raw`,
   `untied_tail`, каждого слоя стека (включая серый `continuum`); «не описано»/«лишнее» — Σ max(±(fit − model), 0)
   (число строки отчёта) и то же против `net` (лента на графике); `rates` — `meta` (χ²/ndf, усиление, сдвиг…),
   `component`/`limit`/`grey` по полям; строки `ROW` и `SCREEN` (имя, значение, подсказка) — дословно;
   строки шапки (`chi2/ndf …`, `состав …`, `шкала …`, `серый слой …`, `отвязанный хвост …`).
6. **Сравнение с эталоном** `reference/<пара>.json`: числа — `|a−b| ≤ abs + rel·max(|a|,|b|)` с допуском ИЗ ЭТАЛОНА
   (умолчание `rel 1e-9`, `abs 1e-6` — по сути побитово, потому что проба детерминирована, §4); строки —
   дословно. Любое расхождение — код 1 и таблица **«спектр — режим — полоса — компонент — было — стало — Δ (Δ %)»**
   (до 60 строк на пару). Дрейф ВХОДОВ (sha спектра, матриц, приборов, библиотеки — в эталоне по члену)
   печатается словами, судят числа. Эталона нет — код 4 («сперва `snapshot.ps1`»).
7. **`--snapshot`** (обёртка `tools/fsa_showcase/snapshot.ps1`) — переобъявление: печатает diff той же таблицей
   против прежнего эталона и переписывает `reference/*.json` (клеймо: дата, HEAD, секунды, ключи, матрица,
   входы, допуск). **`--selftest`** — §6.
