## 1. `AMBER119` — выведенный корень Pb-214 получает Bi-214 ×3.68 — ПОДТВЕРДИЛАСЬ, исправлено

**ДО** (`FsaInferProbeF51` с поставочным корневым `config/NuclideDefinition.xml`, где у Pb/Bi-214 `Chain` пуст,

член, в природе запитан долгоживущим предком), с примечанием «корень выведен разбором… асимптота незапитанного
корня не применена (214BI ×3.6816…; AMBER119)». Веса критерия (`Build` модели) — с тем же флагом.

## 2. `AMBER126` — шумовой пол невязки — ПОДТВЕРДИЛАСЬ, исправлено печатью пола рядом

**ДО** (`ResidualFloorProbeP168`, модель = истинное среднее, 400 пуассоновых копий, `20-…`): «не описано» при
идеальной модели — 3σ над фоном **308 %**, 30σ **36.6 %**, 100σ 11.0 %; 8192 кан. × 10⁴ отсч. **27.4 %** (ревизия
писала 36 % — гаусс вместо пуассона при μ ≈ 1.2), 4096 × 10⁵ 6.3 %.

**Правка.** Число — площадь ленты (решение Amber по `S111`), из него ничего не вычитается. `FsaResult.ResidualNoiseShare`
— ожидаемая E[max(r,0)] идеальной модели по полосе / измеренные отсчёты: без фона — точно по Пуассону
e^{−μ}μ^{k+1}/k!, с фоном — гаусс с дисперсией пробы и приведённого фона. Окно отчёта — первой пометкой подписи
невязки «шумовой пол N %» (от 0.05 %) с подсказкой.

**ПОСЛЕ** (`21-…`): пол = средней доле копий во всех семи режимах (308/301, 36.6/36.8, 11.0/11.0, 27.4/27.5,
6.26/6.27, 0.99/0.99, 58.8/58.9 %); доли — побитово прежние. На витрине: радоновый фильтр «+92.5 / −57.6 %» при
поле 36.5 %, `ASN16_Cs137_10cm` «+16.9 / −17.0» при поле 16.2 % — модель там от идеальной не отличима.

## 3. `AMBER118` — предупреждение об интерференции 186 кэВ — сделано по решению Amber

Решение Amber 28.09.2026, дословно: «Строка AMBER: предупреждение об интерференции 186 кэВ». Имён в коде нет:
`FsaSampleLibrary.NaturalCompanionInterference` — у компонента состава ищется первичный предок (T½ ≥ 10⁸ лет,
`nuclides.abundance` > 0, компонент — член его подряда `T259`), у предка — другие первичные изотопы того же
элемента вне его ряда и вне состава; отношение активностей — из распространённостей и периодов (U-235/U-238
0.04606); линии подряда спутника в окне ±ПШПВ ложатся на ГЛАВНУЮ группу линий строки; множитель = (своё +
спутник)/своё с эффективностью, порог ×1.05. Результат — `FsaResult.LineInterferences`, окно отчёта — строка блока
качества «186.2 кэВ: вклад U-235 не учтён — при природном отношении U-235/U-238 строка Ra-226 завышена до ×1.81» /
«не учтён» кирпичным. Спутник в состав не добавляется (`S110` в силе).

Проверено (`30-…`, `G1S24_Ra226_Petri`): U-238 без связки — Th-234 92.4 кэВ ×1.88, Ra-226 186.2 ×1.82, Pb-210
46.5 ×1.12; Ra-226 без связки — 186.2 ×1.81; `--sample=226RA` — ×1.81; со связкой, с объявленным U-235, Th-232,
выведенный состав — предупреждений нет. (×1.81, а не ×1.72: у G1S ПШПВ на 186 кэВ 20.6 кэВ, и в окно входят
U-235 194.9 и 205.3.) Первым прогоном поймано: `EnergyToChannel(E)` без числа каналов у этого спектра даёт канал
10000 на любой энергии (окно 6.7 МэВ, ×3.95) — зовётся с числом каналов. Правило главной группы снято замером:
суммой по всем линиям рентген Rn рядом с рентгеном ряда U-235 давал ×3.96.

**Часть ROI** (зона по 186 кэВ ×1.72) — файлы П167, не делалась; текст распорядителю в отчёте.
