## 2. Аудит кода света (гипотеза 1)

Определение: свет события = Σ L_e(E_i) по первичным электронам и квантам релаксации, L_e(E) = E·Y(E), Y — выход
электрона начальной энергии E.

| место | что делает код | вердикт |
|---|---|---|
| `MaterialDatabase.LoadLightYieldPayne` | Y(E) = ∫₀ᴱ local(S_coll(E′))dE′ / E, Пейн III (η, S_Trap, S_Birks), ESTAR, ниже 1 кэВ Joy-Luo, обрыв трека; норма — электрон 661.657 | по определению |
| `AddLight(deposit, te)` | deposit·Y(te) — свет по НАЧАЛЬНОЙ энергии электрона | по определению |
| `ElectronLoss` | свет = (te − тормозное − вылетевшее)·Y(te); перепоглощённые тормозные кванты светят своими электронами | по определению (приближение: вылетающий электрон уносит «яркий» конец трека — на краях ничтожно) |
| `ComptonScatter`/`DopplerEnergy` | Клейн — Нишина + S(x,Z) + доплер, электрону E − E′ − E_связи, вакансия — каскадом EADL (`VacancyElectronsSplit`) | по определению |
| пара | электрон и позитрон порознь, у каждого свой Y; аннигиляция отдельно | по определению |
| δ-электроны | не рождаются (CSDA), свет трека — интегралом Пейна | соответствует модели Пейна |
| **`RemapLightScale`** | строка переводится в шкалу света по **СРЕДНЕМУ свету бина поглощённой энергии**, а не по свету каждого события | **приближение**: в одном бине у края лежат одиночные (тусклые) и многократные (яркие) рассеяния |

Дефекта в формуле света нет. Приближение `RemapLightScale` измерено опытом (§3).

## 5. Сбор света по месту события — форма

Рычаги опыта (`p234_experiment.patch`): свет вклада × (1 + g·(z/H − ½)) × (1 + h·(r²/R² − ½)), z от торца к
источнику (кристалл z ∈ [0, H], передний отражатель при z < 0 — проверено по `Build`), r от оси. Рычаг g моей
сборки повторяет `LightFitP200 --lcg` П231 до сотых (P5 +4.85, P25 +5.25, Петри +3.25, маринелли +1.25 кэВ при
g = −0.05) — положительный контроль.

| сцена | данные | g = −0.05 (средний / поштучный) | h = −0.1, центр ярче (средний / поштучный) | кривая t7 → p200 |
|---|---:|---:|---:|---:|
| P5 | +5.4 ± 0.2 | +4.85 / +5.25 | −1.95 / +0.95 | +3.15 |
| P25 | +0.9…+4.0 | +5.25 / +3.45 | −3.65 / −0.90 | — |
| Петри | +3.9 ± 1.6 | +3.25 / +4.10 | −1.95 / −1.15 | — |
| маринелли | −0.3 ± 0.6 | +1.25 / +2.45 | −7.50 / −8.35 | +3.55 |

* **Кривая (вещество)** — отвергнута: одинаковый сдвиг, данные различаются на 6 кэВ (≈ 8σ).
* **Радиальный сбор, центр ярче** — отвергнут маринелли (−7.5 при любом знаке, дающем P5 > P25).
* **Сбор по глубине, торец к источнику ярче (g < 0)** — порядок «торец > маринелли» и величина P5/Петри
  описываются (g ≈ −0.05…−0.09 плюс общий сдвиг ≈ −1.5 кэВ); P25 неустойчив к окну и доводом не служит.
* SE (объём): при g = −0.05 SE +2.8 (П231) — с данными +2.0 совместимо.

разрешения больших кристаллов; числа для G1S там нет.

## Решение 05.10.2026 (протокол)

Оценка распорядителя по вопросу Amber «в лоб не решить, только допущения и подгонки; у Geant4 та же
проблема — я прав?»: да. Сбор света из первых принципов требует оптики прибора (положение и размер окна
SiPM, отражательная способность и рассеяние TiO2/ESR, шероховатость граней, оптический контакт,
неоднородность легирования Tl) — её нет с точностью до 1 %. У Geant4 оптическая физика есть, но ей нужны те
же неизвестные; в обычном гамма-моделировании Geant4 свет вовсе не трассируют (энергию размывают по ПШПВ),
и эффекта там нет. Величина у нас: края комптона ±1 % (≈5 кэВ на 477 кэВ), разница геометрий одного прибора
≈6 кэВ; фотопики, пики вылета и сумм-пики на месте (rev43); на активности — не мерено, ожидаемо мало.
Предлагались: параметр прибора по отдельному замеру; слой «сдвиг света континуума» в FSA; известное
ограничение.

Решение Amber вопросником 05.10.2026, дословно: **«Если это подгонка, и она не объясняет физику, занеси это
решение в протокол. Подгонками не будем заниматься, так как у каждого прибора будет своя пара неизвестных.
Пусть так и останется невязкой.»** — `AMBER155` закрыта, запись в таблице «Чего делать НЕ надо» `TODO.md`;
