## S181 — сверка линий ставит окно линии БЕЗ карты нуля `adc`, которой построен образ (обслуга)

**Где.** `FsaLineAudit.Group` (`FsaLineAudit.cs:383`, `:397-400`):

```
position = calibration.EnergyToChannel(line.Energy, maxChannels: channels);
double p = gain * position + offset + (lightBeta != 0.0 ? lightBeta * ShiftChannels(...) : 0.0);
```

Анализатор кладёт КАЖДЫЙ бин образа через `LightToChannel`
(`FsaAnalyzer.cs:2374-2384`): канал = `EnergyToChannel(E(0) + (x − z₀)·s)`,
`s = (x₁ − E(0))/(x₁ − z₀)` (`AdcScaleOf`); умолчание `AnchorZero = "adc"` с
12.09.2026 (`:4592`), карта включается при матрице и привязке всегда.
`FsaResult.Gain/OffsetChannels` — усиление и ноль, найденные МНК опор ПОВЕРХ
карты; сверка применяет их к калибровочному положению без карты.

## AMBER70 — пик образа FSA стоит не на энергии линии, а на центре бина `round(E/h)·h` — до ±1 кэВ у каждой линии

**Где.** `ResponseMatrix.Transfer`, канал `Peak` (`ResponseMatrix.cs:1783-1790`):

6.2 / 4.3 / 14.4 %; 511 → −1.0; 661.657 → −0.343 = 0.7 %; 1173.23 → −0.77;
1460.82 → +0.82 = 1.2 % (NaI), 2.8 % (LaBr). Следствие для человека: диполь в
ленте невязки у каждого пика ≈ 0.61·|δ|/σ от высоты пика — 4.7 % (NaI,
60 кэВ), 8.8 % (81 кэВ), 1.1 % (662); `ShiftKev` якорей несёт ±1 кэВ

≤ 0.5 % NaI, до 2.8 % LaBr на 81 кэВ. На ветке `p122-physics23` новый канал
`AnnihilationOutside` наследует то же: 511 встаёт на 512 кэВ (δ = −1.0,
максимум).

**Туда же — `RemapLightScale`** (`EfficiencySimulator.cs:8931`): якорь
`anchorPerBin = light[peak]/w/(peak·binKev)` берётся к центру бина пика, а

состава (мерка: центроид образа против `E` по линиям корпуса и корреляция
