## Что стало

### Конфигурация (`BecquerelMonitor/FWHMPeakDetectionConfig.cs`)

Пять положительно названных полей с умолчанием `true`, проведены через копирующий конструктор
(= `Clone`), `AdoptFrom` (берутся у прибора, как остальные настройки поиска) и XML (публичные
свойства; старый файл без элементов даёт умолчания):
`AtomicXrayForFsa`, `CascadeSummingForFsa`, `BackscatterForFsa`, `EscapeAndAnnihilationForFsa`,
`PileUpForFsa`. Имена — по документу A145, раздел «Контракт настроек расчёта».

### Фасад (`BecquerelMonitor/FullSpectrumAnalysis/FsaCalculationOptions.cs`, новый; строка в `.csproj`)

`FsaCalculationOptions` — снимок семи настроек (`DbLookups`, `ChainEquilibrium` + пять выше) и
ЕДИНСТВЕННАЯ точка, где они становятся внутренними ключами:

* `FromConfig(FWHMPeakDetectionMethodConfig)` / `Of(ResultData)` — снимок (null → умолчания);
* `ApplyTo(FsaAnalyzer)`: `CascadeSumming` → `CascadeSumming` И `CascadeSumPeaks`;
  `Backscatter` → `Backscatter`, а `BackscatterWithMatrix = false` ставится БЕЗУСЛОВНО;
  `EscapeAndAnnihilation` → `FsaAnalyzer.EscapeAndAnnihilation`; `PileUp` → `PileUp`;
  `EscapeGate` НЕ трогается; `SumLayerIncludesContinuum` не трогается;
* `ApplyTo(FsaSampleSpec)`: `AtomicXray`, `Equilibrium`;
* `Stamp` — семь букв в постоянном порядке (`peaks|eq|xray|sum|bs|esc|pu`), часть отпечатка расчёта;
* `ParentGroupingPossible` = `DbLookups && ChainEquilibrium` — условие НАСТРОЕК для радиокнопки родителей.

У типа нет членов `BackscatterWithMatrix`, `EscapeGate`, `SumLayerIncludesContinuum` — поднять их
через фасад нельзя по построению (проверяется отражением в `FsaFlagsProbe`).

### Анализатор (`FsaAnalyzer.cs`)

* Новый ключ `EscapeAndAnnihilation` (умолчание `true`). Фильтр библиотеки в `Analyze` теперь
  читает ДВА правила вместе: SE/DE снимаются, когда `EscapeGate && ResponseMatrix != null`
  (матрица уже несёт вылеты) ЛИБО когда ключ выключен; `Ann-511` (в матрице не живёт) снимается
  только выключенным ключом. Четыре клетки — см. числа ниже.
* `FsaComponentResult.DecayChainRoot` заполняется у обычной колонки из
  `FsaComponent.DecayChainRoot` (для колонки ряда — её имя) и у строк `SplitChainMembers` — именем
  колонки ряда.

### Модель результата и сборка библиотеки

* `FsaComponent.DecayChainRoot` (новое) — ставится в `FsaSampleLibrary.Build` у КАЖДОГО
  излучающего члена ряда из двух и более таких членов, при любом положении равновесия (счёт
  `groupSize` теперь идёт всегда; связка `grouped` по-прежнему требует `spec.Equilibrium`,
  численно ничего не сдвинуто).
* `FsaComponentResult.DecayChainRoot`, `FsaStackLayer.DecayChainRoot` (копируется в
  `SpreadContinuum`).
* `FsaResult.ParentGroupingAllowed` (есть хоть одна строка с непустым `ChainRoot`) и
  `FsaResult.ParentGroupingRefusal` (причина: «члены ряда со свободными амплитудами» / «в составе
  нет ряда распада»; null — допустимо). Правило родительского предела при свободных дочерних НЕ
  изобреталось — модель отдаёт признак недопустимости.
* `FsaResult.IsAnnihilationImage(name)` — одно имя на проект, читатель у фильтра.
* `FsaLibrary.BuildFromPeaks(peaks, defs, crystalFractions, bool atomicXray)` — флажок «атомный
  рентген» для пути по пикам (прежние перегрузки = `true`).

### Пробы

* `FsaFlagsProbe` — два новых раздела ДО окон: таблица «фасад → четыре ключа» (4 положения, с
