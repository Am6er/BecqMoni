# Пятый проход ревизии исправлений FullSpectrumAnalysis, 07.09.2026

## A299 — A298 оставила неверный знаменатель при разных весах

`FsaAnalyzer.FitHuber` теперь заменяет `NdfBase` точным `best.Ndf` только когда
`best.Weights` почленно совпали с `reportWeights`. При Huber или составном шуме
в поле остаётся и затем используется `n − activeCount`.

Это не требуемый знаменатель отчётного остатка. Для линейного оценщика с
матрицей влияния `H`, отчётными весами `W0` и ковариацией отчётного шума `V0`
нужно

`tr(W0 (I − H) V0 (I − H)^T)`.

Контрпример без регуляризации: три наблюдения, одна колонка-константа,
`W0 = V0 = I`, а веса решателя `diag(1, 1, 1/4)`. Тогда каждая строка `H`
равна `(4/9, 4/9, 1/9)`, точный след остатка равен `20/9 ≈ 2.2222`, а код
берёт `n − p = 2`. Ошибка попадает и в `Chi2NdfBase`, и в вычитаемый шумовой
член `ModelResidual`.

Фраза в коде «матрицы H в отчётной метрике нет» не является ограничением:
активные колонки, обратная штрафованная матрица Грама и веса решателя уже
сохранены в `FitResult`; нужные следы можно посчитать малыми матрицами так же,
как `EffectiveNdf`, не строя матрицу `n×n`.

## S155 — S150 сохраняет недоказанные β⁺–γ совпадения запасным ходом

`LoadBetaPlusOfGamma` отказывается от уровневого разбора для изомера, при
отсутствии базы и когда подходящих ENSDF-наборов не ровно один. После этого
`AnnihilationQuantaOfGamma` не отказывается от пары, а возвращает
`2 · branch.BetaPlusShare` для каждой гаммы ветви либо общий маргинальный
`AnnihilationQuanta`, если ветвь не определилась.

Маргинальная доля `P(β⁺ | branch)` не равна `P(β⁺ | gamma)`. На этом смешении
и состоял `S150`; исправление устраняет его только для однозначно разобранных
наборов. По журналу самих исправлений неоднозначны 432 пары «родитель — дочь»,
включая `152EU → 152SM`, поэтому это не чисто аварийный путь. Диагностическая
строка делает приближение видимым, но не делает физически возможной
недоказанную пару.

Без совместного уровня безопасный результат для атомной пары — отсутствие
пары с диагностикой. Альтернатива — сначала однозначно выбрать ENSDF-набор по
состоянию и периоду родителя, а затем использовать уровневый поток.
