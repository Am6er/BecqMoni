## 1. Форма порога: МИНИМУМ из абсолютного и доли вершины

```
порог = min(RefitZ, RefitZRelative · z_max)
```

`RefitZRelative` = 0 (умолчание) возвращает прежнее чисто абсолютное поведение.
`z_max` — наибольшая значимость среди СУДИМЫХ компонентов первого прохода
(`RefitZTopZ`, заведена ~~`T240`~~). Оговорка: доля берётся только при
`z_max > 0`, иначе порог остаётся абсолютным.

### Почему минимум, а не чистая доля — довод ЗАМЕРОМ

Чистая доля (`RefitZRelative · z_max` вместо минимума) двигает и СИЛЬНЫЕ сцены,
где отсев и так работал. На `ASN16_Cs137` вершина 303.78, доля 0.1 дала бы
порог 30.378. Это плечо снято прямо, ключом `--refit-z=30.378`:

| порог | строк в стеке | χ²/ndf | невязка модели |
|---|---|---|---|
| 3 (поставочный) | 5 | 49.181 | 37.1 % |
| 30.378 («чистая доля 0.1») | **4** | **50.299** | 37.0 % |

То есть чистая доля ЛОМАЕТ положительный контроль (а) заданием же и
объявленный. Минимум на сильной сцене возвращает ровно `RefitZ` и не меняет ни
одного бита (§4).

### Почему оговорка про `z_max > 0` — тоже не косметика

Она измерена, а не придумана: на `OBS_UGlass` вершина **0.00**. Без оговорки
порог стал бы 0, то есть отсев перестал бы отвергать что-либо вовсе — беда той
же породы, что `T240`, только с другого конца. С оговоркой сцена остаётся на
абсолютном пороге и не меняется ни на плече 0.1, ни на 0.3, ни на 0.5 (§3).

### Какую долю рекомендую: **0.3**

Доля связывает порог только там, где `f · z_max < 3`, то есть где вершина ниже
`3/f`. Отсюда прямой смысл: **0.3 опускает порог только на сценах, чей самый
значимый компонент слабее 10σ**; 0.1 — слабее 30σ.

Критерий выбора взят такой: правка обязана оживить отсев там, где он был пуст,
и НЕ ТРОГАТЬ ничего там, где он и так работал. По развёртке §3 из шестнадцати
сцен:

| доля | оживила отсев (было пусто) | тронула числа там, где отсев работал |
|---|---|---|
| 0.1 | 3 из 3 | **1** (`G1S24_Cd109_P5`) |
| **0.3** | **3 из 3** | **0** |
| 0.5 | 3 из 3 | 0 |

0.1 отпадает по второму столбцу. Между 0.3 и 0.5 выбрана 0.3 как БОЛЕЕ МЯГКАЯ
при том же охвате: на `G1S16_Mn54_P25` доля 0.5 срезает стек с 5 строк до 3, а
0.3 оставляет 5.

⚠ Шестнадцать сцен — не корпус. Доля выбрана по ним и по правилу, а не по
корпусному прогону; корпусное подтверждение — за распорядителем вместе с
переобъявлением базы.
