# A219 — дверь `AppUi.Reason`: пометка «(2/3)» у уже названной ветви

Полоса F8, 05.09.2026, ветка `pie`. Решение Amber 05.09.2026: **ставить пометку
ветви и у уже названного звена** — «<- (2/3) = выше».

## Посылка строки — сверена с кодом, верна

Плечо `петля через ветвь` (`tools/effmaker/probes/ReasonProbe.cs`, `BranchedLoop`):
узел `AggregateException` с тремя ветвями; первая ссылается на вторую (сосед),
вторая — на узел (предок). Обход `ReasonWalk.Visit`
(`BecquerelMonitor/GlobalConfigManager.cs`):

1. ветвь 1 названа с пометкой `(1/3)`; под ней — ветвь 2 БЕЗ пометки (она
   вложенное первой, `mark == ""`); под ветвью 2 — узел, уже в `seen` →
   сторож петли, знак `<- …`;
2. ветвь 2 как ветвь узла (`mark == "(2/3) "`) — уже в `seen` → тот же сторож
   петли, и после `A185` его знак схлопывается с предыдущим: пометка `(2/3)`
   **не печатается вовсе**;
3. ветвь 3 — `(3/3)`.

Текст ДО правки (артефакт `handover/f8-a219/before.txt`, 180 знаков):

    AggregateException: узел с петлёй <- (1/3) InvalidOperationException: ветвь-сосед <- InvalidOperationException: ветвь-к-предку <- … <- (3/3) InvalidOperationException: ветвь чистая

Пометок в строке `сказано`: `(1/3)` 1, `(2/3)` **0**, `(3/3)` 1. Проба ДО
правки выходила кодом 0 — её эталон `A185` этот текст и ждал.

## Правка

`BecquerelMonitor/GlobalConfigManager.cs`, `ReasonWalk`:

* новый помощник `Above(mark)` приписывает `" <- " + mark + "= выше"`
  (константа `AboveMark = "= выше"`; у `mark` хвостовой пробел, выходит
  `<- (2/3) = выше`);
* **сторож петли**: если у звена есть пометка ветви (`mark.Length > 0`) —
  `Above(mark)`, иначе прежний `Guard()` (голый знак, схлопывание `A185`
  сохранено);
* **«уже названо» по тексту** (`Text.IndexOf(part) >= 0`, правило `A129`):
  прежде — ничего; теперь при непустой пометке — `Above(mark)`; при пустой
  — по-прежнему ничего, текст плеч `цитата`/`половина`/`без класса` байт в
  байт прежний;
* сводка `Reason` и комментарий `Above` называют `A219`.

Текст ПОСЛЕ (артефакт `after.txt` = `final.txt`, 196 знаков):

    AggregateException: узел с петлёй <- (1/3) InvalidOperationException: ветвь-сосед <- InvalidOperationException: ветвь-к-предку <- … <- (2/3) = выше <- (3/3) InvalidOperationException: ветвь чистая

Пометок: `(1/3)` 1, `(2/3)` 1, `(3/3)` 1; знак сторожа один.

## Приёмка — `ReasonProbe`, плечо `петля через ветвь`

Эталон `want` в пробе дополнен звеном `" <- (2/3) = выше"`; две новые
проверки — «пометки (1/3), (2/3), (3/3) по разу» и «у названной ветви
«(2/3) = выше»»; прежняя «текст БАЙТ В БАЙТ эталонный» печатает при
расхождении `ожидалось:` и обе длины. Проверок стало 55 (было 53).

| прогон | дверь | эталон | код | ДА/НЕТ | (1/3)/(2/3)/(3/3) в `сказано` | артефакт |
|---|---|---|---|---|---|---|
| до правки | старая | старый (`A185`) | 0 | 53/0 | 1/**0**/1 | `f8-a219/before_full.txt` |
| после правки | новая | новый | 0 | 55/0 | 1/1/1 | `f8-a219/after_full.txt` |
| **положительный контроль** | старая (временно возвращена, `flip_control.py old`) | новый | **1** | 52/**3** | 1/0/1 | `f8-a219/control_full.txt` |
| итог, правка возвращена | новая | новый | 0 | 55/0 | 1/1/1 | `f8-a219/final_full.txt` |

Контроль печатает расхождение: три `НЕТ`, `длина 180 знаков, ожидалось 196`
и строку `ожидалось: …` с `(2/3) = выше`.

Плеч в пробе 15. `Compare-Object` полных выводов до/после (строки «вернулся
за N мс» сняты) даёт отличие ТОЛЬКО в целевом плече: одна строка `сказано`
заменена, две строки новых проверок добавлены. Остальные 14 плеч сошлись
строка в строку; `after_full` и `final_full` сошлись целиком. Ни у одного
другого плеча пометка не появилась: строки `сказано` с пометками `(i/n)`
до/после — `ветвление` 3/3, `вложенное ветвление` 4/4, `петля через ветвь`
2/**3**, `предел по дереву` 2/2.
