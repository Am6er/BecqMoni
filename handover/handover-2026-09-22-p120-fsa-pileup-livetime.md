## 1. `AMBER49` — образ случайных наложений вынимал ОДИН отсчёт на пару вместо ДВУХ

### 1.1. Вывод формулы (независимо от ревизии)

`N` импульсов при скорости `R`; пары с промежутком меньше разрешающего `τ`: их `N_пар = N·R·τ`. Каждая пара
уносит ДВА импульса с их энергий и приносит ОДИН на сумму:
`s'(E) = s(E) − 2·N_пар·s(E)/N + N_пар·(s⊗s)(E)/N² = s + Rτ·[(s⊗s)/N − 2·s]`.
Колонка образа — `(s⊗s)/N − 2·s`, интеграл `−N` (счёт при наложениях ТЕРЯЕТСЯ). В коде
(`FsaAnalyzer.BuildPileUpComponent`) стояло `(pile[k] − byEnergy[k]) / total`, то есть `(s⊗s)/N − s` — одна убыль.
Амплитуда колонки `A` при нынешней нормировке (`/total`): приход `A·(s⊗s)/N²`, то есть `A/N` — доля пар `Rτ`.
Следствие: при `A/N = f` колонка вынимает из фотопиков `f·s` вместо `2f·s`, недостающие `f·s` берут образы
нуклидов → смещение активности `−f`. Ревизия права по знаку и величине первого порядка.

### 1.2. Мерка — `tools/effmaker/probes/FsaPileUpProbe.cs` (новая)

Подсадка пар с ИЗВЕСТНОЙ долей `f` в измеренный спектр: `N_пар = round(f·N_полосы)`, у каждой пары два отсчёта
разыгрываются по распределению исходного спектра в полосе фита и уходят из своих каналов (внутри канала
координата равномерна между краями), один приходит в канал суммы. Координата сложения — та, в которой анализатор
строит образ: `--form=energy` (сумма энергий, `PileUpLightForm = false`) и `--form=light` (сумма по свету
Λ(E) = r(E)·E кривой `PileUpCurveUsed`, `FsaLightScale` отражением — умолчание приложения). Библиотека собирается
ОДИН раз на чистом спектре (как у витрины: пики → `--set=Cs-137 + K-40` → состав из базы) и подаётся всем плечам.
Цель — образ распада с наибольшей скоростью на чистом спектре (Cs-137). Зерно 1.

Положительный контроль в каждом прогоне — плечо `PileUp = false` на том же подсаженном спектре: без образа убыль
`2f` ловить нечем, смещение обязано быть сильнее `−f` (иначе подсадка не доехала — код 1). Измерено: между `−f` и
`−2f` (часть прихода сумм-континуума ложится на образ нуклида и континуум).
