# AMBER202 — матрица отклика не переносится со спектром (05.10.2026)

Постановка Amber (консоль, 05.10.2026), дословно: **«Запиши ещё одну задачу в Amber. Матрица
отклика не переносится со спектром. Когда я отправляю файл спектра другому пользователю, он
получает его с кривой эффективности, но матрица отклика не присутствует у него. Нужно подумать и
предложить решение.»**

## Что есть сейчас (установлено чтением дерева `f4abe6c8`)

* В файл спектра `ResultData.DeviceConfig` сериализуется целиком, вместе с записью кривой
  эффективности `EfficiencyConfigData`: `Guid`, точки кривой, **геометрия** (`Geometry`, `:96`),
  клеймо счёта `ComputeStamp` (`:129`), ключ `UseResponseMatrix`. То есть получатель имеет ВСЁ,
  из чего матрица считается, кроме самой матрицы.
* Матрица лежит на складе `config\device\response\<Guid кривой>.rmx`
  (`EfficiencyMaker/ResponseMatrixStore.cs`), отдельно от конфигурации — **намеренно**: шапка
  класса объясняет, что положенная в конфигурацию матрица «уезжала бы в каждый сохранённый
  спектр — сотни килобайт, бесполезных получателю». Решение было принято тогда, когда переноса
  никто не просил; теперь просят.
* Читателей склада три: `FullSpectrumAnalysis/FsaAnalysisSession.cs:591` (разбор FSA),
  `DoseRateManager.cs:274` (доза), `Utils/BecquerelCoefficient.cs:841` (коэффициент Бк). Все ищут
  по `Guid` кривой; у получателя файла нет — разбор идёт «БЕЗ МАТРИЦЫ» (по кривой).
* Размеры: `.rmx` рабочих кривых Amber — 445–456 КБ (`OneDrive\Desktop\Debug\config\device\response\`),
  корпусных — до ~700 КБ; файлы спектров Amber (XML) — 300–610 КБ. Встроенная матрица (base64)
  примерно удваивает файл спектра; со сжатием — меньше (не мерено).
* Пересчёт у получателя возможен (геометрия есть), но стоит часов и даёт матрицу с другим шумом
  счёта; при совпадении физики и зерна — побитово ту же (зерно в клейме).

## Варианты решения

1. **Матрица внутри файла спектра** — необязательный блок (сжатый, base64) рядом с записью
   кривой. При открытии: склад получателя не имеет матрицы с этим `Guid` или её клеймо не
   совпадает — берётся встроенная (в память; в склад — при принятии конфигурации прибора).
   Старые версии приложения неизвестный элемент XML пропускают. Цена: ~4–6 ч, файл ×1.5–2.
   Вопрос — всегда или по флажку при сохранении.
2. **Экспорт/импорт матрицы руками** — меню «Экспорт матрицы» / «Импорт матрицы» (`.rmx`);
   отправитель шлёт два файла. ~2 ч. Близко к «сайдкару», который Amber отвергла 16.09.2026
   (`AMBER46`, другой предмет, но тот же дух).
3. **Пересчёт у получателя** — при открытии спектра с геометрией и без матрицы отчёт FSA
   предлагает «Посчитать матрицу из геометрии». ~2 ч; часы счёта на стороне получателя.
4. **Пакет** — «Сохранить как пакет» (`.zip`: спектр + матрица). ~3 ч; новый формат файла.

Рекомендация распорядителя — вариант 1 (ничего не надо делать руками ни отправителю, ни
получателю; клеймо матрицы уже умеет судить, годна ли она к этой кривой).

## Решение Amber

Вопросником 05.10.2026, дословно: способ — **«Внутри файла спектра (Рекомендую)»**; когда класть —
**«Настройка, умолчание ВКЛ (Рекомендую)»** (флажок общих настроек «Сохранять матрицу отклика в
файл спектра», включён).
