## 3. `AMBER85` — низ шкалы: ПОДТВЕРДИЛАСЬ, посылка УЖЕ реальности, ЗАКРЫТА

**Проба** — `FsaComponentDumpProbe` с новыми ключами `--head=<n>` (первые n каналов ленты),

**Что нашлось вместо посылки.** Ревизия считала опасными спектры с E(0) > 0 (11 в корпусе,
худший `G1S24_Na22_P5`, 17.36 кэВ). На карте нуля "adc" (умолчание) у них света ниже E(0)
НЕТ: свет z₀ стоит в нулевом канале, и у `G1S24_Na22_P5` z₀ = 0 — образ по умолчанию гладок
(хвост 0.08 в канале 0 и 0.73…1.00 дальше, `a85_na_adc_before.txt`). Зато зажим той же
строки `:326` — `if (enrg < 0 || enrg < c0) return 0` — бьёт ВТОРОЙ половиной: при E(0) < 0
карта "adc" отдаёт свету 0…|E(0)| кэВ энергии в [E(0), 0), и все они получали канал 0, хотя
полином даёт каналы 0…|E(0)|/шаг. В полном корпусе rev33 E(0) < 0 у большинства понятных
спектров (`G1S16_Mn54_P5` — −43.92 кэВ, то есть 15 каналов). Бугор «ниже E(0)» в чистом

## 7. Находки попутно

* Зажим `EnrgToChannel` в [E(0), 0) при E(0) < 0 касается не только FSA: всякий вызывающий,
  спросивший отрицательную энергию, получает канал 0. В FSA закрыто здесь; у прочих
  вызывающих (график, ROI, поиск пиков) не мерено — строкой отдана распорядителю.
* Порог регистрации АЦП модель не знает (~~`A307`~~ закрыта): после `AMBER85` образ честно
  несёт континуум в подпороговые каналы, где данных нет (`G1S24_Na22_P5`, calib: χ²/ndf
  34.35 → 36.06). Отдельной строки не заводится: пол фита по порогу (`A309`) эти каналы и
  отрезает, на умолчании этот спектр побитово прежний.
