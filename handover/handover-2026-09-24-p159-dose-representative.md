## 2. Что сделано (`BecquerelMonitor/DoseRateManager.cs`)

1. **`ShareTrust(приписано, отсчёты)`** — доверие подобранной энергии по доле приписанного s: x = s/0.2; 0 при
   x ≤ 1/√2, 1 при x ≥ √2, между — **½ + ln x/ln 2** (линейно по логарифму, тем же законом, что вес пола П157).
   Полоса `RepresentativeBand` = 2 стоит ВОКРУГ прежнего порога: на самом пороге доверие ½.
2. **Путь матрицы (`SolveJoint`)**: подбор энергии идёт при доверии > 0 (при s > 0.141); энергия диапазона =
   середина + (доверие по доле · доверие по полу)·(подобранная − середина), строка на ней — `RowAt` с тем же кэшем,
   что у плавного пола. При произведении 1 — прежняя ветвь побитово.
3. **Путь «≈» (`PeakPath`)**: то же произведение; там объяснено 0 и доля 1 — доверие 1, числа побитово прежние.
4. Мерные рычаги `representativeBand`, `representativeCentre` — закрытые статические поля, в приложении в них никто не
   пишет; пробы двигают их отражением (`--set=`).
5. Описание `RepresentativeMinShare` — с правилом, выбором полосы замером и ценой.

Пробы: `DoseShareProbe` (новая); ключ `--set=<рычаг>=<число>` у `DoseGridProbe`, `DoseFloorProbe`, `DoseShareProbe`;
описание `DoseFloorProbe` — остаток П157 закрыт.
