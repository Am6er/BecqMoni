## §0 Вердикт

**Сделано, на корпус не влияет, перезапуск не нужен.** Зазор между отражателем и корпусом,
пришедший БЕЗ вещества (пустое имя, без состава, плотность 0), получает `Air, dry` из библиотеки
веществ на трёх входах геометрии в приложение: разбор `.in` (`GeometryModel.Load`), чтение
конфигурации прибора и файла спектра (сеттер `EfficiencyConfigData.Geometry`), наложение своего
шаблона (`GeometryTemplate.Apply`). **Явно заданное вещество не подменяется никогда** — вода в
живом конфиге Amber остаётся водой (положительный контроль пробы), её Amber правит руками.

Клеймо матриц измерено на всех **61** файле `.in` (46 корпуса + 1 закреплённая копия + 14 моделей):
**разошлось 0 из 61**; все **46 матриц живого склада** (`tools/CORPUS/corpus/geometries/*.rmx`,
физика 18, только чтение) годны против геометрии, разобранной новым кодом (`IsValidFor` — 46 из 46).
Контроли чувствительности: у 6 сцен с ненулевым зазором снятое вещество клеймо МЕНЯЕТ (6 из 6),
у 55 с нулевым вода в зазоре клеймо НЕ меняет (55 из 55) — сравнение не слепое.

## §1 Что найдено

1. **Где стояла дыра.** Пресеты (`GeometryPresets.Wrapping`) и заготовка (`GeometryEditorPanel.Blank`)
   ставят зазору `Air, dry` с 08.09.2026 (`eb0861db`). Но геометрия, ПРИШЕДШАЯ без вещества зазора,
   оставалась с пустым: конфигурация прибора до 08.09 (без `<Gap>`), файл с пустым блоком `<Gap>`,
   `.in` без ключей `DS_*CrystalGap*` (55 из 61 в дереве), шаблон без зазора. Человек, набравший
   толщину, получал предупреждение «нет вещества» (`GeometryModel.CheckLayers`) вместо воздуха.
2. **Комментарий-запрет П14** над разбором `.in` («⛔ Подставлять здесь воздух по умолчанию НЕЛЬЗЯ …»)
   был решением полосы, не Amber, — снят её словом; переписан с приведением слова Amber дословно.
3. **Проба `GapProbeAmber1` (строка 404) ждала пустое имя** у старого файла без ключей зазора —
   это ожидание противоречит новому решению и без правки стало бы красным молча. Проверка переведена
   на «вещество — воздух по умолчанию» с пояснением.
4. **Клеймо.** `ResponseMatrix.StampView` (`dropGap`, 08.09.2026) снимает вещество зазора нулевой
   толщины из клейма; у шести файлов с ненулевым зазором (`AS80_lu_front`, `AS80_point0`,
   `AS80_th_disk`, `pinned/AS80_th_disk` — 21.7 мм; `RC103_lu_front`, `RC103_point0` — 3.5 мм) воздух
   записан в файле ЯВНО (`M_DS_Gap.MName = Air, dry`, `DS_RoCrystalGap = 0.001205`, N/O) и читается
   из файла. Поэтому правка склад не двигает — измерено, §4.
5. **Цена умолчания — подъём базы веществ.** Состав `Air, dry` считается из формулы `N2 O1` через
   атомные массы `matdb.sqlite`; первый вызов `DefaultGapMaterial()` в процессе поднимает базу.
   Измерено пробой (Debug, машина под счётом П97 на 8 потоков): первый разбор `.in` без зазора —
   **325 мс**, второй — 0 мс. Умолчание зовётся ТОЛЬКО у геометрии с пустым зазором (у заданного
   до базы дело не доходит), то есть в приложении цену платит один раз тот, у кого в конфигурации
   есть геометрия без вещества зазора (конфиги до 08.09.2026). Следствие для отказа базы — §5.
