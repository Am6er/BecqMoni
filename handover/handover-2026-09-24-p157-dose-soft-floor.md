## 2. Что сделано (`BecquerelMonitor/DoseRateManager.cs`, `DoseRate.cs`)

1. **Вес диапазона** `FloorWeight`: доля x в полах (`own / (0.01·max)`) — 0 при x ≤ 1, 1 при x ≥ `FloorBand` = 2,
   между — **ln x / ln 2**. Выше максимума кривой (`S186`) — прежнее правило: вес 1 при доле > 0, иначе 0.
2. **Путь «≈»**: доза и поток диапазона × вес; вес 0 — снят, как прежде.
3. **Путь матрицы (совместное решение `S185`)**: доза линии диапазона × вес, и её отклик в ЧУЖИХ диапазонах (комптон,
   хвост пика) объясняет их отсчёты с тем же весом — в системе `SolveCounts` (столбец линии вне своей группы × вес),
   в вычитании при подборе энергии, в окне центра тяжести, в слиянии `MergeLeaks` (избыток и утечка), в итоговом
   «объяснено». Уравнение слитого диапазона в полосе складывается с соседом с его весом; сосед в полосе входит в окно
   центра тяжести с его весом. Иначе вход диапазона в систему на самом поле переставлял бы соседей скачком.
4. **Вторая ступенька пола — проверка на представительной энергии** (П145: «доля на подобранной энергии ниже пола —
   остаёмся на середине»). После п.1–3 она дала скачок −0.76 % на `ASN16_Cs137_10cm` (17.22…22.59 кэВ, энергия 18.05 →
   19.90 кэВ на сдвиге порога 0.9 %). Теперь и она плавная: энергия = середина + вес(доля на подобранной)·(подобранная
   − середина); строка матрицы на этой энергии считается `RowAt` и кэшируется.
5. **Покрытие** — по весам каналов: диапазон в полосе покрыт в меру веса (приписка «covers N %» непрерывна).
6. `DoseRateRange.Weight` (1 — целиком, 0 — снят, между — полоса); `FluenceRate` и `DoseRate` — с весом, `Cps` и
   `Attributed` — без.
7. Мерные рычаги `floorFraction`, `floorBand` — закрытые статические поля, в приложении в них никто не пишет; их
   двигает только проба отражением.

При весе 1 все выражения — прежние побитово (умножение на 1.0 точно; ветки `== 1.0` сохраняют прежний порядок
сложения) — это подтверждено прогонами (§3).

### 2.1 Форма и ширина перехода — замером

**Форма — линейно по логарифму доли.** Проба мерит |d ln Ḣ/d ln порога|; у веса w(ln x) на отрезке [0, ln B] из всех
монотонных переходов 0 → 1 наибольший наклон наименьший у линейного (1/ln B; у кубической ступени — 1.5/ln B).

**Ширина** (`DoseFloorProbe`, та же сборка, рычаг `floorBand`, показание на штатном пороге к полосе 2 и худшая
производная на сетке 150 шагов):

|---|---|---|---|---|---|
| 1.25 | +3.65 % | +0.61 % | 0 | +0.006 % | 0.59 / 0.36 |
| 1.5 | +3.65 % | +0.21 % | 0 | +0.006 % | 0.34 / 0.20 |
| **2** | **0** | **0** | **0** | **0** | **0.23 / 0.12** |
| 3 | −2.91 % | −0.11 % | −0.07 % | −0.003 % | 0.18 / 0.07 |
| 4 | −3.92 % | −0.15 % | −0.54 % | −0.004 % | 0.15 / 0.06 |

G1S и RC-103 по матрице, AS80 по матрице от ширины не зависят (там нет диапазонов в полосе 1…4). Уже двух —
производная растёт как 1/ln B (0.59 при 1.25); шире двух — производная падает медленно (0.23 → 0.15), а на штатном
