### 1.3 Оценка «чистого ослабления» μ(E)·ρ·путь (гипотеза как она сформулирована) и её проверка измерением

Модель (`mk_arms.py`, `R_MODEL`): r(E) = f·2E₃(μ(E)·t) + (1 − f) — пропускание слоя при косинусном падении внешнего
поля, μ — полное ослабление XCOM из `matdb` (только чтение), маринелли t = 2.2 см (сбоку 24.5 мм, над колодцем
19 мм), f = 0.8 (почти всё внешнее поле к кристаллу идёт сквозь пробу); цилиндр — t = высота засыпки сцены, f = 0.25.
**Проверка ТОЙ ЖЕ формулой на измеренном случае «вода против пусто»:** модель даёт 0.47 / 0.57 / 0.60 / 0.65 / 0.77 /
0.82 / 0.87 на 35 / 55 / 75 / 135 / 600 / 1250 / 2400 кэВ, данные — 1.25 / 1.29 / 1.28 / 1.27 / 0.995 / 0.936 /
0.927. **Модель отвергнута измерением**: ниже 300 кэВ ошибка знака (×2…×2.7), выше 700 кэВ ослабление завышено
втрое (−18 % против −6 %). Сцены внешнего поля с пробой нет (её нет и в П338: их r(E) — развёртка Geant4 по фону
воды). Поэтому числа плеча D ниже — **верхняя граница** эффекта «ослабления», а не его оценка.
