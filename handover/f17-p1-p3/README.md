## Что видел человек

* Окно настроек прибора на русской системе печатало период измерения, число
  каналов, шаг канала и **все коэффициенты энергетической калибровки** с
  запятой, а поле разбирало текст по культуре потока — и напечатанную самим
  приложением точку **не принимало вовсе**, молча отдавая НОЛЬ.
* На немецкой системе то же поле молча делало из «0.5» число **5**, а из
  «-2.5» — **-25** (точка там законный разделитель разрядов).
* Русский набор «1 5» с неразрывным пробелом прежде принимался как **15**;
  теперь разделитель разрядов не принимается ни на одной культуре.
