## 2. Правка (`BremsstrahlungData.cs`)

1. **`SampleFrom` обращает ту же интерполяцию, что `Interpolate`** (`AMBER139`). Доля квантов выше node[i] при
   T — ((1 − f)·N_lo·C_lo(i) + f·N_hi·C_hi(i)) / N(T): смесь двух узловых распределений с весами по ЧИСЛУ квантов
   (`photons` у толстой, `thinPhotons` у тонкой), её момент — интерполированный `Radiated`. Одно равномерное
   число на квант, как было (поток ГСЧ не меняется), энергия монотонна по u. Верхний бин [node_lo, node_hi]
   несёт только кванты верхнего узла и частью лежит выше T — он сжат по log k в [node_lo, T]: квант не
   энергичнее электрона.
2. **Энергия бина таблицы — по форме розыгрыша** (`BinEnergy`, тоже `AMBER139`): розыгрыш внутри бина
   равномерен по log k, а энергия бралась трапецией по k. Только с п. 1 проба показала систематический остаток
   +0.19 % выше 100 кэВ и до +1.76 % у 6 кэВ (`handover/p183` не хранит этот промежуточный замер — он в
   `D:\BqMoni_Claude\p183\art\11-probe-new-a.txt`). Теперь энергия бина = число × (k1 − k0)/ln(k1/k0), и
   подтяжка к ESTAR делает РАЗЫГРАННУЮ энергию равной выходу ESTAR. Следствие: число квантов толстой мишени
   ниже на ту же долю (CsI Photons(661.657) 0.35087 → 0.35021, −0.19 %).
3. **`Bracket` вместо `IndexBelow`** (`AMBER140`): интервал lo ∈ [0, n − 2] с node[lo] ≤ T < node[lo + 1], первый
   интервал свой — экстраполяции нет.
4. **Кончик тонкой мишени** (находка П183, починена на месте): в `BuildThin` у верхнего бина dσ/dk(k = T)
   бралось 0.0, а χ(κ = 1) у Зельцера — Бергера конечна (у толстой ноль верен: путь от k до T пуст). Замер по
   сечениям той же `matdb`: верхний бин таблицы был на 40–48 % меньше трапеции с кончиком; сам кончик — 0.31 %
   квантов и 1.73 % энергии тонкой мишени у узла 284 кэВ, 0.11 % / 1.00 % у 1093, 0.07 % / 0.78 % у 2451
   (CsI; у NaI так же, у Al вдвое меньше). Теперь d1 = PerGram(κ = 1).
